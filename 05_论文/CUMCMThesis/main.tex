\begin{abstract}

微网可在电价低谷充电、高峰放电，在满足小区负载的前提下降低购电费用。本文以
混合整数线性规划为核心工具：先建立问题一的单日确定性购电计划模型，再针对问题二
负载与光伏逐日变化、计划不足须按 $5$ 倍电价紧急补购的情形，建立"预测—风险修正
—日前优化—实时执行"的三层滚动模型。

\textbf{问题一}将全天离散为 $144$ 个 $10$ 分钟时段（$\Delta t = 1/6$~h），以
\textbf{电量}（kWh）为决策单位，变量含计划购电量、充放电量、弃光电量与时段末
储电量，并以二元变量保证充放电互斥；目标为全天购电费最小。约束包括供需平衡、
状态递推（单程效率 $0.90$，往返效率 $0.81$）、容量 $[1200,10800]$~kWh 与日循环
$E_0=E_{144}=6000$~kWh。该 MILP 共 $864$ 个变量，由 HiGHS 求得\textbf{全局最优
解}；LP 松弛的最优解中同时充放电时段数为零且目标值一致（差 $7.3\times10^{-12}$
元），说明它本身已是原模型最优解。结果：全天计划购电量 $59482.70$~kWh、购电费
$35126.95$~元（均价 $0.5905$~元/kWh），储能充放电量之比恰为往返效率 $0.81$，
储电量两端均被\textbf{紧约束}触及，\textbf{全天弃光电量为零}。灵敏度分析表明
$10$ 分钟粒度较 $4$ 小时粒度节省 $24.3\%$，本模型较"无储能"与"无光伏无储能"
方案分别节省 $26.90\%$ 与 $60.23\%$。

\textbf{问题二}的电价仍逐日相同，负载与光伏改为附件 2 的全年实际值。
\textbf{预测层}先识别出负载存在极强星期结构（周一至周四及周日约 $124000$~kWh/日，
周五、周六仅约 $78000$~kWh/日），而光伏以季节性为主，故采用按周衰减的近期加权
预测、负载只用同星期历史日，使净负荷预测的日绝对误差由 $19796.2$ 降至
$3116.9$~kWh/日。\textbf{计划层}注意到少买须付 $5$ 倍罚款、多买不退款，由一阶
条件可得最优计划量应取净负荷的\textbf{$80\%$ 分位数}，遂用历史\textbf{预测误差}
（而非拟合残差）的经验分位数构造风险净负荷 $\widetilde N=\widehat N+Q_{\alpha}$，
求解含日末储备软约束的日 MILP，在 $0{:}00$ 冻结全天 $144$ 段计划购电量。
\textbf{执行层}逐段观测实际值，按因果规则决定充放电、紧急购电与弃电，实际日末
储电量传给次日，不要求日循环；参数由滚动窗口的实际总费用标定。

以 2025 年 1 月为预热期，正式区间为 2 月 1 日--12 月 31 日共 $334$ 天。计划购电量
$21701732.99$~kWh、紧急购电量 $124045.19$~kWh，\textbf{合计购电费
$14021565.12$~元}，其中紧急购电费 $662827.17$~元、仅占 $4.73\%$。$8$ 次滚动
标定选出的 $\alpha$ 全部落在 $0.70$--$0.90$（$0.80$ 出现 $6$ 次），\textbf{与
理论导出的 $80\%$ 分位数高度吻合}。相对本策略自身费用，较"预测均值策略"节省
$7.44\%$、较"无储能策略"节省 $32.34\%$，"事后理想"乐观下界为 $12082248$~元。
信息时点、物理可行性、跨日连续性、状态累计、费用一致性与汇总一致性六项强制
检查全部通过。

\textbf{问题三}在每天 $0{:}00$、$6{:}00$、$12{:}00$、$18{:}00$ 各获得一次
未来 $24$ 小时的预报，且调整购电量按 $1.5$ 倍电价收费。为消除"同一时段被多次
修订如何结算"的歧义，本文严格区分三个量：\textbf{初始计划量} $g_t^0$（$0{:}00$
冻结、永久保存）、\textbf{最终生效量} $x_t$（完整量而非增量）与\textbf{紧急购
电量} $r_t$，实际收到电量为 $G^{\mathrm{received}}=\sum x_t+\sum r_t$；并采用
\textbf{交付块策略}，每个六小时块只在块首正式调整一次。附件 3 经对齐扫描判定
为\textbf{整点瞬时功率}（对齐偏差 $191.51$~kW，显著优于平移一小时与按小时平均），
版本内作分段线性插值。由 $5p\Pr(N>x)>1.5p$ 得临界分位数由 $0.8$ 降至 $0.7$；
调减不退款时另有 $Q_{0.9}$，二者构成 $[Q_{0.7},Q_{0.9}]$ 的"不必调整区间"。
$0{:}00$ 计划沿用问题二的 MILP，此后三个时点以\textbf{当前实际储电量}为初值滚动
重排，仅提交当前块。四种预报的精度依次提高（全天电量偏差 $3903.9/2110.0/
1197.7/461.3$~kWh/日）。全年 $334$ 天回放结果：\textbf{合计购电费 $13457697.61$
元}（计划 $12492137.14$、调整 $675387.19$、紧急 $290173.29$），较仅用 $0{:}00$
预报的 $14207402.23$ 元节省 $5.28\%$；其中 $73.2\%$ 来自状态刷新与滚动重优化、
$26.8\%$ 来自新发布的预报版本本身。全年七项强制检查全部通过，主口径下全年调减量恒为零。边际分析
表明 \textbf{$18{:}00$ 与 $6{:}00$ 的预报不可替代，而 $12{:}00$ 在已有
$\{6,18\}$ 时仅再省 $1.68$ 万元（$0.12\%$），可以省去}。

\keywords{混合整数线性规划\quad 微网调度\quad 储能优化\quad 峰谷套利\quad
风险分位数\quad 滚动决策\quad 灵敏度分析}
\end{abstract}

% ---------------------------------------------------------------- 1 问题重述
\section{问题重述}

\subsection{问题背景}

微网是为解决光伏发电等分布式能源本地消纳、减少并网问题而快速发展起来的小型
发用电系统。出于经济方面的考虑，非孤岛式微网可在外部电网（以下简称外网）
电价较低或分布式能源有剩余电量的时间段为储能设备充电，并在外网电价较高的
时间段释放电能。

微网与外网调控的目标是：利用小区负载、光伏发电量和储能设备当前储电量等数据，
尽可能精准地给出微网的购电量和储能设备的充放电量，使微网提供的电力既满足
小区负载，又尽可能节省购电费用。

\subsection{问题提出}

\textbf{问题一}：若每天的电价和小区负载相同，同时给出光伏发电功率一天的预测
数据，要求微网提供的电能不低于小区负载，且储能设备在 $0{:}00$ 和 $24{:}00$
的储电量相同。需要在每天 $0{:}00$ 制定微网当天计划购电策略的数学模型；
根据附件 1 和附录 1 的数据给出具体策略，并以规定格式给出指定时段的购电量、
全天购电量与购电费，以及储能设备的充放电量与 $0{:}00$、$24{:}00$ 储电量，
完整策略保存至 \texttt{result1.xlsx}。

\textbf{问题二}：若每天的电价相同，而小区负载和光伏发电功率随时间变化，且
微网提供的电能不可低于小区负载，如果低于负载需向外网紧急购电，其电价是交易
时刻电价的 $5$ 倍；除紧急购电费用外，其他时间段的购电费用均按计划购电量
计算。需要在每天 $0{:}00$ 制定当天的计划购电策略。根据附件 1 的电价和附件 2
的数据，给出表 3 中指定日期（2025.3.20、2025.6.21、2025.9.23、2025.12.21）
的结果，并以规定格式给出紧急购电结果，完整策略保存至 \texttt{result2.xlsx}。

% ---------------------------------------------------------------- 2 问题分析
\section{问题分析}

三问共享同一套物理模型（储能、平衡与效率约束），差别全部在\textbf{信息的可得性}
与\textbf{计费规则}上。本节只辨认每问的结构性难点与应对路线，具体模型在第 5--7
节展开。

\subsection{问题一分析}

问题一的关键在于识别其\textbf{确定性}与\textbf{单日性}：各日运行条件完全相同，
光伏又是给定的一日预测，故只需制定一个具有代表性的单日计划（附件 5 中
\texttt{result1.xlsx} 仅含 $144$ 行，亦印证这一点）。

设定下微网面临的是\textbf{带储能的多时段能量调度问题}，节费来自两条相互关联的
渠道：\textbf{峰谷套利}（低价多购存入储能、高价放电替代购电）与\textbf{光伏
消纳}（把光伏盈余存入储能留待无光照时段）。二者都要求决策\textbf{跨时段协调}
——某段多买一度电会改变后续所有时段的可行域，故不能逐段贪心，必须整体优化。
数学结构上，目标与全部约束（平衡、递推、容量、互斥）都是线性的，除模式变量
$z_t\in\{0,1\}$ 外是 LP；引入 $z_t$ 后为 MILP，其解的最优性可由分支定界严格
保证。

需要辨析的建模要点有四，详见第 5.2 节：(1) 以\textbf{显式弃光变量}把平衡写成
等式，使富余光伏的去向可追踪；(2) 充电在平衡式中属于"消耗"，须与购电、光伏
放在同一式联合考虑；(3) 日循环约束使单日模型可逐日重复而不漂移，并由递推式
推出 $\sum_t d_t=\eta_c\eta_d\sum_t c_t$ 这一强校验关系；(4) 同一时段不得同时
充放电，必须用二元变量强制互斥，否则在光伏免费富余或存在多重最优解时求解器
可能返回违反物理约束的解。

\subsection{问题二分析}

问题二引入三处本质改变。

\textbf{其一，信息结构由"完全已知"变为"逐日滚动"。}负载与光伏改为每天都在
变化的实际值，$0{:}00$ 制定计划时当天尚未发生，因此必须引入预测环节，且预测、
误差统计与参数选择都必须\textbf{严格遵守信息时点}。这是本题最容易在实现中被
违反的地方：一旦某个统计量（如分位数）不小心用到了当天或未来的数据，算出的
费用只是"虚假的优秀"。本文以结构隔离保证这一点——预测器只暴露 $i<n$ 的历史，
分位数只取 $i<n$ 的误差样本。

\textbf{其二，代价的不对称为风险定价提供了明确依据。}多买 $1$~kWh 的确定成本
是 $p$，少买的期望成本是 $5p\Pr(N>g)$。令二者相等得 $F_N(g)=0.8$：\textbf{最优
计划量是净负荷分布的 $80\%$ 分位数}，该结论不依赖任何分布假设。更关键的是，
它说明真正决定费用的是预测误差的\textbf{分位数结构}而非均值，因此本文不追求
最小化 MAE，而在点预测上叠加历史误差的经验分位数作为风险余量。加入跨时段储能
后 $80\%$ 不再具有全局最优性，故它只作为参数搜索的起点，最终由实际连续运行的
总费用标定。

\textbf{其三，跨日状态必须连续。}问题二不再要求 $E_0=E_{144}$，这不是简单的
"放宽"，而\textbf{改变了问题结构}：电池成为真正的跨期资源。其后果有三：
(1) 不能固定用 $6000$~kWh 作每日初值，必须传递当天\textbf{实际执行后}的日末
电量；(2) 问题一的强校验关系不再成立，应改用状态累计关系
$\Delta E=\eta_c\sum_t c_t-\eta_d^{-1}\sum_t d_t$；(3) 单日模型倾向于日末放空
电池，故可在目标中加入日末储备软惩罚 $\lambda\xi$ 抑制短视——标定结果为
$\lambda=0$，即在该评价口径下数据认为不需要它，且无论取值如何该惩罚
\textbf{只用于制定策略，不计入实际上报的账单}。

综合三点，问题二应建成\textbf{"预测—风险修正—日前优化—实时执行—跨日滚动"}
的多层结构；整条链路的优劣只能由\textbf{按时间顺序的实际运行回放}评价，评价
口径必须是包含 $5$ 倍紧急购电费的\textbf{实际总费用}，而非预测误差。

\subsection{问题三分析}

问题三把信息结构与计费规则同时改动，二者的耦合是本题难点。

\textbf{其一，信息从"一个点预测"变成"一串被反复修订的版本"。}每天有
$0{:}00$、$6{:}00$、$12{:}00$、$18{:}00$ 四个版本，各覆盖其后 $24$ 个整点。
这带来三个新要求：(1) 每条预报必须\textbf{同时}携带"发布时间"与"目标时间"
——附件 3 的"预报 1 小时"指发布后 $1$ 小时而非当天 $1{:}00$，混用会造成整体
错位；(2) 首端没有 $F_0$，必须显式约定一个\textbf{不引入未来信息}的锚点；
(3) 更晚发布的版本未必更准，其价值必须用实际运行费用衡量，不能由"更新"本身
推出。

\textbf{其二，计费规则的改变直接改写了风险定价的阈值。}问题二中多买 $1$~kWh
的确定成本是 $p$、少买的期望成本是 $5p\Pr(N>g)$，临界比给出 $80\%$ 分位数。
问题三中调增 $1$~kWh 的确定成本是 $1.5p$，于是追加是否值得的条件变为
$5p\Pr(N>x)>1.5p$，即
$$
\Pr(N>x)>0.3
\quad\Longleftrightarrow\quad
x^*=\max\{g^0,\;Q_{0.7}(N)\},
$$
这种"由边际成本比给出最优分位数"的做法与库存管理中的临界比规则同源
\cite{ref:newsvendor}。反过来，若采用"取消部分退款"的解释，调减 $1$~kWh 净省
$0.5p$、代价是 $5p\Pr(N>x)$，得 $\Pr(N>x)=0.1$，即\textbf{缺口概率低于 $0.1$
时才值得调减}。两种口径合起来给出 $[Q_{0.7},Q_{0.9}]$ 的\textbf{"不必调整
区间"}——这正是"有新预报不等于一定要改计划"的定量表述，第 7.8 节用八种预报
组合的实际费用对它作了检验。该推导忽略储能与跨时段价值，只用于解释机制，
实际参数仍由连续回放的实际总费用标定。

\textbf{其三，决策由"一次冻结"变成"分区段依次正式提交"。}问题三中
$6{:}00$、$12{:}00$、$18{:}00$ 都可修改计划，于是必须回答：同一时段被修改多次
按哪一次结算？本文采用\textbf{交付块}策略，让每个六小时交付块只在其块首正式
调整一次（块范围见第 7.1 节）：每个十分钟时段只与自己的 $g_t^0$ 结算一次，
"最终净偏差结算一次"与"逐次变更累加"的歧义被彻底消除；更远时段的取值只作为
\textbf{展望值}参与，不提交、不收费、不写入结果文件。

由此，问题三应建成\textbf{多次预报驱动的滚动购电与调整模型}。回答"是否需要
其他时刻的预报"不能只看四个指定日期，必须把 $8$ 种预报组合逐一完整回放全年，
并另设一个\textbf{在同一时刻重新优化、但仍沿用 $0{:}00$ 预报版本}的对照，以
分离"新信息带来的收益"与"重新优化带来的收益"。

% ---------------------------------------------------------------- 3 模型假设
\section{模型假设}

\begin{enumerate}
  \item \textbf{数据准确假设}：附件 1 的电价、小区负载与光伏功率准确反映实际，
        不计预测误差（其影响留待问题三）。
  \item \textbf{分段恒定假设}：每个 $10$ 分钟时段内各功率恒定，时段电量等于功率
        乘以 $\Delta t = 1/6$~h；供电保障对应这一离散模型。
  \item \textbf{母线侧计量假设}：$c_t$ 为微网送入储能的电量、$d_t$ 为储能向微网
        交付的电量，均按\textbf{微网母线侧}口径计量，额定功率同侧解释。
  \item \textbf{储能理想假设}：单程效率恒为 $\eta_c=\eta_d=0.90$（往返 $0.81$），
        不随功率、储电量、温度或设备老化变化，无自放电与漏电损失。
  \item \textbf{单向购电假设}：题目未给出售电价格，$g_t \ge 0$，不计余电上网收益。
  \item \textbf{弃光可行假设}：光伏出力超过负载且储能无法完全吸纳时允许弃光，
        $0 \le s_t \le v_t$，富余光伏总有确定去向。
  \item \textbf{不外加上网限值假设}：附录中 $5000$~kW 限制的是\textbf{储能设备}
        的充放电功率，本文不另设微网购电功率上限。
  \item \textbf{无紧急购电假设}：问题一中计划购电得到完全执行，不触发因计划
        不足而生的紧急购电（该情形在问题二中讨论）。
  \item \textbf{日循环假设}：储能每日回到当日 $0{:}00$ 的水平，即 $E_{144}=E_0$，
        该计划可逐日重复执行。
  \item \textbf{忽略衰减假设}：不计容量衰减与寿命损耗成本。
\end{enumerate}

问题二改用以下假设（与问题一冲突处以本节为准）：

\begin{enumerate}
  \setcounter{enumi}{10}
  \item \textbf{电价逐日重复假设}：附件 1 的日内电价在 2025 年每天重复生效，
        不使用附件 4 的波动电价（留待问题四）。
  \item \textbf{实际值可观测假设}：当天运行时，各时段的实际负载与光伏在该时段
        结束时可被观测并用于该时段记账；执行层以 $10$ 分钟为记账步长。
  \item \textbf{预测信息受限假设}：$0{:}00$ 制定计划时只能使用当天之前的负载
        与光伏实际值、已知的日内电价、日期与星期，以及当前实际储电量；当天
        实际曲线与附件 3 的外部光伏预报均不可使用。
  \item \textbf{计划购电量冻结假设}：$g_{n,t}$ 一经 $0{:}00$ 确定便不再修改，
        不足部分只能按 $5$ 倍电价紧急补购，无计划调整交易（留待问题三）。
  \item \textbf{紧急购电不退款假设}：已按计划购入的电量无论用完与否均全额收费，
        用不完的部分可转为充电，其余按无收益弃用处理，即\textbf{允许弃用已购电}。
  \item \textbf{储备惩罚不计入账单假设}：软惩罚项 $\lambda\xi_n$ 只用于制定策略，
        \textbf{绝不进入实际上报的购电费}。
\end{enumerate}

\section{问题一：单日计划购电优化模型}

\subsection{数据预处理与时段划分}

附件 1 共给出 $144$ 组数据，涵盖一天 $24$ 小时，故将一天等分为
$T = 144$ 个长度为 $\Delta t = 10\ \text{min} = 1/6\ \text{h}$ 的时段。

需要特别说明时段标签的对应关系：附件 1 的时间列为区间\textbf{结束时刻}
（首行 $0{:}10$、末行 $0{:}00{+}1$），其中 $0{:}00{+}1$ 按题目附录 2 的规定表示
当天 $24{:}00$。因此附件 1 的第 $t$ 行对应时段
$[(t-1)\Delta t,\ t\Delta t)$，即第 $t$ 时段为 $(t-1)\times 10$ 分钟至
$t \times 10$ 分钟，该行的电价与功率作为这一区间的代表值。

这一理解与"储能设备在 $0{:}00$ 和 $24{:}00$ 的储电量相同"的日循环约束相互
印证：只有末行的 $0{:}00{+}1$ 代表 $24{:}00$，$24{:}00$ 才是可约束的时刻。
需要指出，附件 5 中 \texttt{result1.xlsx} 的"计划购电量"表首段标签为
$0{:}10$--$0{:}20$、末段为 $0{:}00{+}1$--$0{:}10{+}1$，其末段已越过当天，
与正文要求的 $0{:}00$--$24{:}00$ 口径整体错位一格。本文统一采用正文口径，
在输出副本中将购电时间标签改写为 $0{:}00$--$0{:}10$ 至 $23{:}50$--$0{:}00{+}1$，
行序与模板一一对应，原始模板文件保持不变。若后续有题目勘误或补充说明，
应据此调整。

\textbf{单位换算}：附件 1 中电价为元/kWh，负载与光伏功率为 kW。为便于与题目
结果表逐项对应，本文不直接以功率作决策变量，而是先把负载与光伏换算为时段
电量，再以\textbf{电量}为决策变量单位：

\begin{equation}
  \ell_t = L_t\,\Delta t, \qquad v_t = V_t\,\Delta t .
  \label{eq:unit}
\end{equation}

图~\ref{fig:p1-profiles} 给出附件 1 三类输入数据的全天变化特征：电价呈明显的
双峰结构，早高峰位于 $7{:}50$--$9{:}10$（峰值 $1.1683$~元/kWh）、晚高峰位于
$17{:}40$--$20{:}50$，最高电价 $1.3952$~元/kWh（出现在 $20{:}30$--$20{:}40$），
而夜间低谷约 $0.42$~元/kWh、全天最低 $0.3713$~元/kWh（出现在
$5{:}30$--$5{:}40$），峰谷
价差达 $3.76$ 倍，为峰谷套利提供了充足空间；小区负载在 $8{:}00$--$18{:}00$
维持在 $4208$~kW 以上、峰值 $5958.97$~kW（出现在 $9{:}00$--$9{:}10$），夜间
回落至约 $3400$~kW；光伏出力呈标准钟形
分布，$4{:}30$ 前后开始发电，正午达到峰值 $7612.32$~kW，$19{:}20$ 后归零，
全天有 $55$ 个时段出力为零。三者共同决定了优化问题的基本格局。

需要强调，题目所说的"每天的电价相同"指的是\textbf{每天重复同一条电价曲线}，
而非一天内电价恒定。附件 1 的电价每 $10$ 分钟都有具体数值，故本文不作峰谷
电价粗化，直接在 $10$ 分钟粒度上建模。

\subsection{模型建立}

\subsubsection{决策变量}

对每个时段 $t = 1, 2, \dots, 144$，定义如下决策变量（前四个以电量 kWh 计）：

\begin{itemize}
  \item $g_t \ge 0$：从外网购入的电量（kWh）；
  \item $c_t \ge 0$：向储能设备输入的充电量（kWh）；
  \item $d_t \ge 0$：储能设备向微网输出的放电量（kWh）；
  \item $s_t \ge 0$：弃用的光伏电量（kWh）；
  \item $E_t$：第 $t$ 时段末的储电量（kWh），$t = 0, 1, \dots, 144$；
  \item $z_t \in \{0,1\}$：充放电模式变量，$z_t = 1$ 表示该时段允许充电、
        $z_t = 0$ 表示允许放电。
\end{itemize}

注意 $E_0$ 是 $0{:}00$ 电量、$E_{144}$ 是 $24{:}00$ 电量，因此储电量序列共有
$\mathbf{145}$ 个状态点。

\subsubsection{目标函数：全天购电费最小}

微网的购电费用仅来自从外网购入的电量，故目标为最小化全天购电费：

\begin{equation}
  \min\ J = \sum_{t=1}^{T} p_t\, g_t .
  \label{eq:objective}
\end{equation}

由于 $g_t$ 已经是电量（kWh），此处不再乘 $\Delta t$。应注意目标是购电
\textbf{费用}最低而非购电\textbf{总量}最低：低价充电带来的能量损耗可能使
全天购电量上升，但仍能降低总费用。

\subsubsection{约束条件}

\textbf{（1）供需平衡约束（等式加显式弃光）}

微网在第 $t$ 时段可用电量由外网购电、扣除弃光后的光伏出力与储能放电三部分
构成，须恰好等于小区负载耗电与储能充电之和：

\begin{equation}
  g_t + (v_t - s_t) + d_t = \ell_t + c_t, \qquad t = 1,2,\dots,T
  \label{eq:balance}
\end{equation}

\textbf{（2）光伏与购电的非负及弃光上界}

\begin{equation}
  g_t \ge 0, \qquad 0 \ \le\ s_t \ \le\ v_t, \qquad t = 1,2,\dots,T
  \label{eq:curtail}
\end{equation}

式 \eqref{eq:balance}--\eqref{eq:curtail} 完整满足负载，并通过显式弃光变量
处理多余光伏。相比把供电条件写成不等式 $g_t+v_t+d_t-c_t \ge \ell_t$，
等式加弃光变量的写法可以直接追踪富余电量的去向，更方便解释和检查。
$s_t$ 的上界取 $v_t$ 表明弃光量不可能超过光伏发电量本身。

\textbf{（3）储能电量递推约束}

第 $t$ 时段末的储电量由上一时段末的储电量、本时段的充电量与放电量决定：

\begin{equation}
  E_t = E_{t-1} + \eta_c\, c_t - \frac{d_t}{\eta_d},
  \qquad t = 1,2,\dots,T
  \label{eq:recursion}
\end{equation}

其中 $\eta_c = \eta_d = 0.90$。这里不能把充电项与放电项都乘以 $0.90$——
两者都是母线侧电量，但一个流入电池、一个流出电池：充入 $1$~kWh 电量，电池
内部增加 $0.9$~kWh；向微网放出 $1$~kWh 电量，电池内部需减少 $1/0.9$~kWh。
该设定对应储能\textbf{往返效率} $\eta_c\eta_d = 0.81$。当 $t = 1$ 时
$E_{t-1} = E_0$，即 $0{:}00$ 的初始储电量。

\textbf{（4）储电量运行区间约束}

为避免过度充电或放电，储电量须全程保持在给定区间内，$145$ 个状态点逐一受限：

\begin{equation}
  E_{\min} \ \le\ E_t \ \le\ E_{\max}, \qquad t = 0,1,\dots,T
  \label{eq:socbound}
\end{equation}

其中 $E_{\min} = 1200$~kWh，$E_{\max} = 10800$~kWh。

\textbf{（5）功率上限与充放电互斥约束}

受逆变器与电池倍率限制，单个 $10$ 分钟内最大充电量与最大放电量均为

\begin{equation}
  M = P_{\max}\,\Delta t = 5000 \times \frac{1}{6} = \frac{2500}{3}\ \text{kWh},
  \label{eq:M}
\end{equation}

并利用二元变量约束同一时段不能同时充放电：

\begin{equation}
  0 \ \le\ c_t \ \le\ M z_t, \qquad
  0 \ \le\ d_t \ \le\ M(1-z_t), \qquad
  z_t \in \{0,1\}, \qquad t = 1,2,\dots,T
  \label{eq:mutex}
\end{equation}

$z_t = 1$ 时允许充电、放电量被压为零；$z_t = 0$ 时允许放电、充电量被压为零；
两种模式下都可以令充放电量同时取零，表示待机。

\textbf{（6）日循环约束}

题目要求储能设备在 $0{:}00$ 与 $24{:}00$ 的储电量相同，结合附录 1 给出的
$2025$ 年 $1$ 月 $1$ 日 $0{:}00$ 电量为 $6000$~kWh，有：

\begin{equation}
  E_0 = E^{\mathrm{init}} = 6000, \qquad E_T = E_0
  \label{eq:cycle}
\end{equation}

该约束保证计划可逐日重复执行：若 $24{:}00$ 储电量与 $0{:}00$ 不同，则次日
初始条件将发生漂移，单日模型无法描述长期运行。同时它也使得模型无法通过
额外消耗初始库存来获取不公平的费用优势。

由状态递推式 \eqref{eq:recursion} 对全天求和，结合日循环条件
\eqref{eq:cycle}，可推出一个很有用的校验公式：

\begin{equation}
  \eta_c \sum_{t=1}^{T} c_t = \frac{1}{\eta_d}\sum_{t=1}^{T} d_t
  \quad\Longrightarrow\quad
  \sum_{t=1}^{T} d_t = \eta_c\eta_d \sum_{t=1}^{T} c_t = 0.81 \sum_{t=1}^{T} c_t .
  \label{eq:cycle-check}
\end{equation}

因此，日初日末储电量相同\textbf{并不意味着}表中的全天充电量等于全天放电量，
二者之比应恰为往返效率 $0.81$。

\subsubsection{完整模型}

综合以上各式，问题一的数学模型为：

\begin{equation}
\begin{aligned}
  \min_{g,\,c,\,d,\,s,\,E,\,z} \quad & J = \sum_{t=1}^{144} p_t\, g_t \\[2pt]
  \text{s.t.} \quad
  & g_t + (v_t - s_t) + d_t = \ell_t + c_t, && t = 1,\dots,144 \\
  & E_t = E_{t-1} + \eta_c c_t - \frac{d_t}{\eta_d}, && t = 1,\dots,144 \\
  & E_{\min} \le E_t \le E_{\max}, && t = 0,\dots,144 \\
  & 0 \le c_t \le M z_t, \quad 0 \le d_t \le M(1-z_t), && t = 1,\dots,144 \\
  & 0 \le s_t \le v_t, \quad g_t \ge 0, && t = 1,\dots,144 \\
  & z_t \in \{0,1\}, && t = 1,\dots,144 \\
  & E_0 = E_{144} = 6000
\end{aligned}
\label{eq:full-model}
\end{equation}

\subsubsection{模型类别：MILP 及其 LP 松弛}

模型 \eqref{eq:full-model} 中，目标函数与全部约束关于决策变量均为线性，
唯一的非线性来源是 $z_t \in \{0,1\}$ 这一整数要求，因此这是一个
\textbf{混合整数线性规划（MILP）}，可以直接表达充放电互斥，适合作问题一的
完整主模型。

按变量排列
$x = [\,g_{1:T},\ c_{1:T},\ d_{1:T},\ s_{1:T},\ E_{1:T}\,]^{\mathsf{T}}
\in \mathbb{R}^{5T}$，并记 $z = [z_1,\dots,z_T]^{\mathsf{T}}$，模型
\eqref{eq:full-model} 可写成如下标准形式：

\begin{equation}
  \min_{x,\,z}\ \bar{c}^{\mathsf{T}} x
  \quad \text{s.t.} \quad
  A_{\mathrm{eq}}\begin{bmatrix}x\\z\end{bmatrix} = b_{\mathrm{eq}}, \quad
  A_{\mathrm{ub}}\begin{bmatrix}x\\z\end{bmatrix} \le b_{\mathrm{ub}}, \quad
  l \le x \le u, \quad z \in \{0,1\}^{T}
  \label{eq:milp-standard}
\end{equation}

其中目标系数 $\bar{c}$ 仅在购电变量位置取 $p_t$；等式约束
$A_{\mathrm{eq}}$（共 $144+144+1 = 289$ 条）对应供需平衡
\eqref{eq:balance}、状态递推 \eqref{eq:recursion} 与日循环条件
\eqref{eq:cycle}；不等式约束 $A_{\mathrm{ub}}$（共 $288$ 条）对应互斥约束
\eqref{eq:mutex}；边界 $l,u$ 对应 \eqref{eq:curtail} 与 \eqref{eq:socbound}。
完整模型共 $5\times144 + 144 = \mathbf{864}$ 个决策变量、$289$ 条等式约束与
$288$ 条不等式约束，且所有非零系数均取自
$\{0, \pm1, \pm\eta_c, \pm 1/\eta_d\}$，不含任何非线性项。

\textbf{LP 松弛的作用。}去掉整数要求 $z_t \in \{0,1\}$（即令
$0 \le z_t \le 1$）、仅保留 $0 \le c_t, d_t \le M$，模型退化为一个普通的 LP。
该 LP 的最优值是 MILP 最优值的\textbf{下界}，可用于核对数据、检查约束并
提供费用下界的参照。更重要的是：\textbf{如果 LP 最优解本身不含同时充放电，
则它满足完整模型，便已经是 MILP 的最优解。}这一判定由程序自动完成——先求解
LP，统计 $c_t^*$ 与 $d_t^*$ 同时为正的时段数，再求解 MILP 与之比较。需要
强调的是，\textbf{不能仅凭电价为正就假定求解器一定不会返回同时充放电}：
存在免费光伏富余、多重最优解或数值退化时，LP 松弛仍可能给出物理上不可执行的
解。因此本文不依赖这一先验假设，而是以数值判定为准。

本模型在结构上还是一个\textbf{网络流型线性规划}：储能可视为一个连接各时段的
"水库"，$E_t$ 是水位，$c_t$ 与 $d_t$ 分别是入库与出库流量。求解器采用
HiGHS，其 LP 部分以并行对偶修正单纯形法为核心，MILP 部分以分支定界配合
割平面求解，问题规模（$864$ 变量）在该求解器下属小规模问题。

\subsection{模型求解}

\subsubsection{求解方法与算法}

本文使用 Python 科学计算栈中的 \texttt{scipy.optimize.milp} 接口调用
\textbf{HiGHS} 求解器（当前主流的开源 LP/MILP 求解器），以稀疏矩阵存储
约束系数，对 LP 松弛与完整 MILP 分别求解。求解参数为默认的 $10^{-7}$ 量级
可行性容差。

求解流程为：

\begin{enumerate}
  \item 读取附件 1 的电价、负载与光伏三类序列，校验时段标签严格递增、等间隔
        且恰好覆盖当天 $144$ 个时段，确保时段口径成立；
  \item 按式 \eqref{eq:unit} 将功率换算为时段电量，整理容量、功率、效率与
        日初电量等参数；
  \item 按 \eqref{eq:milp-standard} 装配目标向量、约束矩阵与变量边界，
        分别构造 LP 松弛与完整 MILP；
  \item 调用 HiGHS 求解，记录求解状态、目标值与最优性间隙；
  \item 对解进行独立复核（供需平衡、状态递推、物理边界、日循环、充放电互斥、
        费用复算），并判定 LP 松弛解是否已是 MILP 最优解；
  \item 由通过校验的解汇总论文表格、绘制策略图，并按统一时间标签写出
        \texttt{result1.xlsx}。
\end{enumerate}

\subsubsection{求解结果与 LP/MILP 一致性}

LP 松弛与完整 MILP 的求解结果如下：

\begin{itemize}
  \item \textbf{LP 松弛}：最优费用 $35126.9486$~元；最优解中
        $c_t^*$ 与 $d_t^*$ 同时为正的时段数为 $\mathbf{0}$；
  \item \textbf{完整 MILP}：最优费用 $35126.9486$~元，最优性间隙
        $0$（已证明全局最优）；最优解同样不含同时充放电。
\end{itemize}

两模型的目标值相差 $7.3\times10^{-12}$~元，仅为浮点舍入量级。由于 LP 松弛
的最优解本身不含同时充放电，它自动满足互斥约束 \eqref{eq:mutex}，因而也是
完整模型 \eqref{eq:full-model} 的最优解。\textbf{该结论由数值判定独立得到，
未使用"电价为正"这一先验假设。}本文后续所有结果均取自这一（同时是 LP 与
MILP 的）最优解。

\subsubsection{求解结果的校验}

为确保结果可信，对最优解独立复核了以下各项，\textbf{全部通过}：

\begin{enumerate}
  \item \textbf{时段完整性}：$144$ 个时段完整覆盖当天 $0{:}00$--$24{:}00$，
        首尾与四小时分组均无错位；附件 1 时间标签经校验为
        $\{10,20,\dots,1440\}$ 分钟且严格递增。
  \item \textbf{逐段供需平衡}：$\max_t\bigl|g_t+v_t-s_t+d_t-\ell_t-c_t\bigr|
        < 10^{-6}$~kWh。
  \item \textbf{状态递推}：由 $c^*,d^*$ 从 $E_0$ 出发独立累计递推得到的
        储电量序列与求解器返回的 $E^*$ 最大偏差小于 $10^{-6}$~kWh。
  \item \textbf{物理边界}：$E^*$ 全程落在 $[1200,10800]$~kWh 内；
        $c_t^*,\,d_t^* \le M = 2500/3$~kWh；$0 \le s_t^* \le v_t$；
        且不存在同时充放电的时段。
  \item \textbf{日循环}：$E_{144}^* = E_0^* = 6000$~kWh，且按式
        \eqref{eq:cycle-check} 校验 $\sum_t d_t^* = 0.81\sum_t c_t^*$
        （实测 $16799.94 / 20740.67 = 0.810000$）。
  \item \textbf{费用与汇总}：用未四舍五入的数据重新计算
        $\sum_t p_t g_t^*$，与求解器返回值一致；各分段汇总与全天明细一致。
\end{enumerate}

数值复核仅设置极小的浮点容差，\textbf{未通过删除负数、裁剪越界值或修改末段
结果的方式掩盖任何约束违背}。

\subsection{结果分析}

\subsubsection{购电策略的时序特征}

图~\ref{fig:p1-purchase} 给出全天逐时段的计划购电量与电价的对照关系。可以
清晰地看到购电行为被\textbf{严格地压缩到了低电价时段}：

\begin{itemize}
  \item 在 $0{:}00$--$6{:}00$ 的夜间低谷（电价约 $0.37$--$0.91$~元/kWh），
        购电量维持在每 $10$ 分钟 $1400$~kWh 上下，其中 $0{:}00$--$0{:}40$
        因需同时供给负载并为储能充电而达到全天最大的
        $1406.6$--$1409.8$~kWh/10\,min；
  \item 在 $5{:}30$--$5{:}40$ 电价降至全天最低（$0.3713$~元/kWh）时，购电量
        为 $1383.66$~kWh/10\,min，仍处高位；此后随储能充满
        （$5{:}40$ 触及上限 $10800$~kWh）迅速退出购电，$5{:}50$ 起连续
        $31$ 个时段购电量降为零；
  \item 在 $7{:}50$--$9{:}10$ 与 $17{:}40$--$20{:}50$ 两个电价高峰段
        （电价最高达 $1.3952$~元/kWh，约为低谷的 $3.76$ 倍），购电行为被
        显著抑制：早高峰 $7{:}30$--$10{:}00$ 的购电量\textbf{恰好为零}，
        完全由储能放电支撑；晚高峰 $17{:}00$--$21{:}00$ 购电量回落至
        $0$--$826.08$~kWh/10\,min（$24$ 个时段中仅 $12$ 个时段有购电），
        降幅虽大但仍保留了部分购电——因为此时储能储电量已接近下限，
        继续放电将破坏后续时段的供电能力；
  \item 在光伏出力超过小区负载的 $9{:}30$--$14{:}20$（共 $30$ 个时段）内，
        购电量在 $22$ 个时段\textbf{降为零}，微网完全由光伏供电并有盈余为
        储能充电；其余 $8$ 个时段（$11{:}00$--$12{:}30$）仍有
        $179.28$--$575.17$~kWh/10\,min 的购电。这并非供电需要，而是模型
        捕捉到了正午时分电价出现的局部低谷（$0.4113$--$0.5007$~元/kWh，
        低于相邻时段）：此时储能尚有充足容量（储电量由 $2971$~kWh 升至
        $9144$~kWh），故在光伏已经富余的情况下仍提前购入低价电存入储能，
        留待傍晚 $1.3952$~元/kWh 的高价时段使用。这正是
        表~\ref{tab:p1-buy} 中 $10{:}00$、$14{:}00$、$20{:}00$ 三个时段购电量
        为零、而 $12{:}00$、$16{:}00$、$18{:}00$ 仍保留一部分购电的原因
        ——$16{:}00$、$18{:}00$ 的购电则是因储电量已达上限 $10800$~kWh、
        光伏出力已低于负载，只能由外网补足。
\end{itemize}

这一策略正是"谷充峰放"的定量体现：模型把所有可推迟的购电需求都转移到了
电价最低的时段。用边际条件可以解释这一行为：忽略容量与功率限制时，在低价
时段购入 $1$~kWh 电量用于充电，未来只能向负载交付 $\eta_c\eta_d$~kWh，
故跨时段购电储能具有经济性的条件为 $p_{\text{低}}/\eta_c\eta_d <
p_{\text{高}}$。代入 $\eta_c\eta_d = 0.81$，只要峰谷价差超过约 $1.23$ 倍
即值得套利，而附件 1 的实际峰谷比达 $3.76$，套利空间充裕。实际充电时段
则由优化模型在综合考虑光伏富余、后续峰值价格、剩余容量与日末恢复电量后
自动确定。

制约进一步降低购电费的关键瓶颈。这一发现对实际工程具有直接意义——适当

\subsection{基准对照与灵敏度分析}
\label{sec:sensitivity}

为量化储能与光伏的经济价值，本文构造"光伏供电、缺口直接外购、电池保持不动"
的基准方案（它是原问题的一个可行解，故给出同一口径下的费用上界）；针对题目
只给出一个"充放电效率 $90\%$"、其单程/往返分配方式存在解释空间的情况，又设计
了效率分配、日循环水平与决策粒度共六组对照口径。两组对照的完整数据与逐项
推理见附录~\ref{app:extra}，正文只保留结论。

\begin{enumerate}
  \item \textbf{储能的价值不止于价差套利。}配置储能后全天购电费由 $48052.05$~元
        降至 $35126.95$~元，\textbf{节省 $12925.10$~元（降幅 $26.90\%$）}；
        较"无光伏无储能"方案节省 $53192.41$~元（$60.23\%$）。含储能方案的
        购电量反而更少（$59482.70$ 对 $61789.94$~kWh），因为它把无储能时
        被迫弃掉的 $6247.96$~kWh 光伏盈余转移到了无光照时段，
        \textbf{提升了光伏本地消纳率}。
  \item \textbf{效率约定影响有限，主要结论稳健。}单程与往返两种解释构成购电费
        区间 $[33416.53,\ 35126.95]$~元，跨度不足 $5\%$；两种口径下"谷充峰放"
        的策略结构与零弃光结论均不变。
  \item \textbf{决策粒度具有实质经济价值。}决策由 $10$ 分钟粗化为 $1$ 小时时，
        购电费上升 $4.68\%$ 并产生 $768.44$~kWh 弃光；粗化为 $4$ 小时时上升
        $24.26\%$（$43648.06$~元），弃光增至 $2293.67$~kWh。因此采用
        $10$ 分钟粒度是必要的，这也印证了题目以 $10$ 分钟为间隔要求购电量的
        合理性。
  \item \textbf{给定的初始储电量已接近最优循环水平。}解除 $E_0=6000$~kWh 的
        固定约束后模型收敛到 $E_0=8550$~kWh，购电费仅下降 $8.35$~元
        （$0.024\%$），无需为此偏离题目给定值。
\end{enumerate}

\section{问题二：预测驱动的滚动日前计划与实时执行模型}

\subsection{问题二相对问题一的三个本质变化}

问题二放宽了问题一的确定性设定：\textbf{电价仍逐日相同}（重复使用附件 1 的
日内曲线），但\textbf{小区负载与光伏出力改为附件 2 给出的全年实际值}，且
\textbf{计划购电不足时须按交易时刻电价的 $5$ 倍紧急补购}。这带来三个必须在
模型中显式处理的变化：

\begin{enumerate}
  \item \textbf{信息约束}：每天 $0{:}00$ 制定计划时，当天的负载与光伏实际值
        尚未发生，只能依据此前历史预测，不能提前读取待预测当天的实际曲线；
  \item \textbf{代价不对称}：少买需要按 $5$ 倍价格紧急补购，多买仍按计划量
        全额收费且\textbf{不予退款}。两侧代价不对称，意味着"平均预测误差最小"
        不再是正确的优化目标；
  \item \textbf{跨日状态连续}：问题二没有再要求每天 $0{:}00$ 与 $24{:}00$ 的
        储电量相同，因此电池状态必须\textbf{跨日连续传递}，不能每天重置为
        $6000$~kWh，也不能套用问题一"全天放电量为充电量的 $0.81$ 倍"这一
        关系（该关系以首尾电量相等为前提）。
\end{enumerate}

相应地，模型由问题一的\textbf{单日确定性 MILP} 扩展为\textbf{三层滚动结构}：
预测层（逐日预测负载与光伏）$\to$ 计划层（在风险修正净负荷下求解日 MILP，
冻结当天 $144$ 段计划购电量）$\to$ 执行层（逐段观测实际值，因果地决定充放电、
紧急购电与弃电，并把实际日末储电量传给次日）。

\subsection{数据准备、时间口径与信息时点}

附件 2 提供 2025 年 $365$ 天、每天 $144$ 个 $10$ 分钟时段的负载功率与光伏
实际功率，经校验无空值、无负值、日期严格递增且恰好覆盖
$2025{:}01{:}01$--$2025{:}12{:}31$。全天合计负载 $40524.1$~MWh、合计光伏
$20251.2$~MWh，功率范围分别为 $1995.72$--$7978.88$~kW 与
$0$--$10216.20$~kW。

时段口径与问题一完全一致：附件 2 的列标签同样采用区间\textbf{结束时刻}，
故第 $j$ 列对应区间 $[(j-1)\Delta t,\ j\Delta t)$。附件 5 中
\texttt{result2.xlsx} 的"计划购电量"表首段标签为 $0{:}10$--$0{:}20$、末段为
$0{:}00$--$0{:}10{+}1$，与问题一模板一样整体错位一格。本文在输出副本中
按正文口径统一改写为 $0{:}00$--$0{:}10$ 至 $23{:}50$--$0{:}00{+}1$，
行序与模板一一对应，原模板文件保持不变。

\textbf{信息时点纪律}：$2025$ 年 $1$ 月被指定为训练与状态预热期，不进入正式
结果；正式输出与评价区间为 $2$ 月 $1$ 日至 $12$ 月 $31$ 日，共 $334$ 天。
$2$ 月 $1$ 日的初始储电量由 $1$ 月逐日实际运行自然递推得到，而非人为设定。
每天的预测、误差分位数与标定参数一律只使用当天之前的已完成数据，计划电量
$g_{n,t}$ 在 $0{:}00$ 一经确定便不再修改。

\subsection{预测模型：先识别数据中的结构性规律}

预测方法的选择不应先验假定，而应从数据出发。本文对附件 2 的 $365$ 天数据
做了两项结构性检验：

\textbf{（1）负载存在极强的星期结构。}把全年按星期分组求日总电量均值，得到
周一至周四及周日约为 $123900$--$124144$~kWh/日，而周五、周六仅约
$78332$--$78407$~kWh/日，两者之比达 $1.58$ 倍。这一结构是\textbf{整体水平}
上的：两族的日内归一化形状高度相似（相关系数 $0.888$，同样呈现凌晨低谷、
上午高峰、午间回落、午后次高、入夜走低的形态），但并不完全一致——以周五、
周六一族为基准，族间逐时段相对差的中位数为 $8.9\%$，在傍晚 $17{:}30$ 前后
最大可达 $38.5\%$（该族在傍晚的相对水平明显更低），而到日末 $23{:}50$ 处
又反向相差 $30.9\%$（周五、周六的相对水平反而更高）。因此若把不同星期的
历史日混在一起做加权平均，既会把两族水平"平均掉"、又无法刻画这一形状差异，
产生系统性偏差。

\textbf{（2）光伏不存在星期结构，而以季节性为主。}按星期分组的光伏日电量均值
极差仅 $1.80\%$，且与星期无明显对应关系，故光伏预测应侧重\textbf{最近的}
历史曲线以跟踪季节变化。

据此采用"近期加权历史值"的预测形式：

\begin{equation}
  \widehat{\ell}_{n,t}=\sum_{i\in\mathcal{H}_n}a_{n,i}\,\ell_{i,t},
  \qquad
  \widehat{v}_{n,t}=\sum_{i\in\mathcal{H}_n}b_{n,i}\,v_{i,t},
  \qquad
  a_{n,i},\,b_{n,i}\ \ge 0,\quad \sum_i a_{n,i}=\sum_i b_{n,i}=1
  \label{eq:p2-forecast}
\end{equation}

其中权重按"周"衰减，$w_{n,i}=d^{\,(n-1-i)/7}$。负载预测取回看窗口
$15$ 天、周衰减因子 $d=0.30$，并\textbf{只保留与待预测日同一星期的历史日}；
光伏预测取回看窗口 $5$ 天、$d=0.50$，使用全部历史日。两组超参数只依据
$1$ 月的数据选定，在正式区间开始前即行冻结，此后不再调整，从而不引入未来
信息。

"是否按星期分组"这一结构选择可由 $1$ 月数据\textbf{独立判定}：在 $1$ 月的
$30$ 天上，\textbf{不区分星期}与\textbf{区分星期}的净负荷日绝对误差分别为
$20173.9$ 与 $5903.7$~kWh/日，相差 $3.4$ 倍。在回看窗口取 $7$、$14$、$21$、
$28$ 天、衰减因子取 $0.5$ 与 $1.0$ 的 $1$ 月网格上重复比较，不区分星期一族的
误差落在 $19304.8$--$20173.9$~kWh/日，区分星期一族落在
$5824.3$--$5903.7$~kWh/日，\textbf{两族区间互不重叠}（比值 $3.3$--$3.5$ 倍），
故该结构结论不依赖窗口与衰减因子的具体取值。下述对照与精度指标则在正式区间
（$2$ 月 $1$ 日--$12$ 月 $31$ 日）上统计，属于对该结构选择的
\textbf{事后评价}：\textbf{不区分星期}时误差为 $19796.2$~kWh/日，
\textbf{区分星期}后降至 $3116.9$~kWh/日，改善约 $6.4$ 倍。这一差距并非窗口
长度等超参数造成的假象——在回看窗口取 $7$、$14$、$21$、$28$ 天、衰减因子取
$0.5$ 的一组设定下，不区分星期方案的误差始终稳定在 $19498$--$19512$~kWh/日；
而\textbf{同样把这组窗口用于区分星期方案}，误差稳定在 $3035$--$3302$~kWh/日。
换用逐时段口径复核结论一致：逐段绝对误差和由 $20162.9$~kWh/日
降至 $6372.4$~kWh/日（$3.2$ 倍）。
正式区间上的预测精度见表~\ref{tab:p2-totals}：负载平均绝对误差
$1823.4$~kWh/日（相对 $1.65\%$）、光伏 $2077.9$~kWh/日（$3.64\%$）、净负荷
$3116.9$~kWh/日。

上面三个指标都是\textbf{逐日全天电量}口径的绝对误差，取绝对值后抹去了方向，
而本题的代价恰恰是\textbf{不对称}的——低估触发 $5$ 倍紧急购电，高估只造成
弃电。因此另按\textbf{逐时段}口径统计两个方向，见表~\ref{tab:p2-totals}：
实际净负荷高于点预测的时段占 $49.1\%$、合计 $3181.9$~kWh/日（低估时段平均
低估 $45.0$~kWh/段）；低于点预测的时段占 $50.9\%$、合计 $3190.5$~kWh/日。
两个方向在\textbf{频次与电量上都几乎对称}（$49.1\%$ 对 $50.9\%$，
$3181.9$ 对 $3190.5$），说明点预测本身没有系统性的偏高或偏低，误差结构是
"噪声型"而非"偏差型"。这意味着继续改进预测方法难以再获益，收益只能来自对
\textbf{同一个误差分布}选取合适的分位数——这正是下一节的出发点。

令净负荷预测为 $\widehat N_{n,t}=\widehat\ell_{n,t}-\widehat v_{n,t}$。
注意\textbf{不把负的净负荷截为零}：负值表示光伏有余，是可以存入储能的信息，
截断会白白丢失。

\subsection{风险余量：为何可以从 $80\%$ 分位数出发}

设某时段随机净负荷为 $N$，计划购电 $g\ge 0$。忽略储能时，期望费用为

\begin{equation}
  \min_{g\ge0}\ pg+5p\,\mathbb{E}\bigl[(N-g)_+\bigr],
  \qquad (x)_+=\max(x,0).
  \label{eq:p2-newsvendor}
\end{equation}

若 $N$ 的分布连续且最优解位于 $g>0$，一阶条件给出

\begin{equation}
  \frac{\partial}{\partial g}=p-5p\,\Pr(N>g)=0
  \quad\Longrightarrow\quad
  F_N(g)=\frac{5-1}{5}=0.8 .
  \label{eq:p2-critical}
\end{equation}

即\textbf{最优计划量是被 $5$ 倍紧急电价推高到 $80\%$ 分位数}的位置：多买
$1$~kWh 的确定成本是 $p$，少买 $1$~kWh 的期望成本是 $5p\cdot\Pr(N>g)$，
二者在 $F_N(g)=0.8$ 处平衡。这一结果给出风险参数一个清楚的经济解释，但它
\textbf{只在忽略储能与跨时段耦合时严格成立}，因此本文把它作为参数搜索的
起点而非结论，最终由实际连续运行的总费用校准。

实践中无法直接得到 $N$ 的分布，转而对\textbf{净负荷预测误差}建模。对每个
已经结束的历史日期 $i$，保存其当时利用更早数据作出的预测，计算误差

\begin{equation}
  \varepsilon_{i,t}=(\ell_{i,t}-v_{i,t})-\widehat N_{i,t\mid\text{日期}<i} .
  \label{eq:p2-error}
\end{equation}

\textbf{这里用的是逐日预测后得到的真实预测误差，而不是模型在训练数据上的
拟合残差}——后者会显著低估实际误差。取此前 $28$ 天内对应时段误差的经验
$\alpha$ 分位数 $Q_{\alpha,n,t}$，构造风险修正净负荷：

\begin{equation}
  \widetilde N_{n,t}=\widehat N_{n,t}+Q_{\alpha,n,t} .
  \label{eq:p2-risk}
\end{equation}

第 $n$ 天的分位数只取 $\varepsilon_{i,t}$（$i<n$）中已结束日期的样本；
历史样本不足 $10$ 个时改取该时段 $\pm2$ 个相邻时段合并后的分位数，冷启动
阶段仍有可用估计。直接对净负荷误差建模，还自动保留了负载误差与光伏误差
之间的相关性。

\subsection{日前计划模型：风险净负荷下的 MILP}

每天 $0{:}00$ 求解一次。决策变量以\textbf{电量}（kWh）为单位：计划购电量
$g_{n,t}$、参考充电量 $\bar c_{n,t}$、参考放电量 $\bar d_{n,t}$、参考剩余
电量 $\bar w_{n,t}$、参考储电量 $\bar E_{n,t}$，以及模式变量
$z_{n,t}\in\{0,1\}$。带横线的变量表示\textbf{日前参考计划}，不是实际执行结果。

\textbf{目标函数}除购电费外，加入日末储备不足的软惩罚：

\begin{equation}
  \min\ \sum_{t=1}^{144}p_t\,g_{n,t}+\lambda\,\xi_n,
  \qquad
  \xi_n\ \ge\ E^{\mathrm{tar}}-\bar E_{n,144},\quad \xi_n\ \ge\ 0 .
  \label{eq:p2-obj}
\end{equation}

$E^{\mathrm{tar}}=6000$~kWh 是希望为次日保留的参考电量，$\lambda$（元/kWh）
是储备不足的规划代价。引入它的目的是减轻"只优化一天、日末过度放电"的短视
倾向。需要强调，\textbf{该惩罚只用于制定策略，绝不计入实际上报的购电费}。
本文并不预设 $\lambda$ 的取值，而是把它与 $\alpha$、$\rho$ 一并交给数据标定
（见 \ref{sec:p2-calib} 节）。

\textbf{约束条件}包括四组：

\begin{equation}
\begin{aligned}
  & g_{n,t}+\bar d_{n,t}=\widetilde N_{n,t}+\bar c_{n,t}+\bar w_{n,t},
  && g_{n,t}\ge0,\ \bar w_{n,t}\ge0 \\
  & \bar E_{n,t}=\bar E_{n,t-1}+\eta_c\,\bar c_{n,t}
    -\frac{\bar d_{n,t}}{\eta_d},
  && \bar E_{n,0}=E_{n,0}^{\mathrm{actual}} \\
  & E_{\min}\le\bar E_{n,t}\le E_{\max},
  && E_{\min}=1200,\ E_{\max}=10800 \\
  & 0\le\bar c_{n,t}\le M z_{n,t},\quad
    0\le\bar d_{n,t}\le M(1-z_{n,t}),
  && z_{n,t}\in\{0,1\}
\end{aligned}
\label{eq:p2-model}
\end{equation}

其中 $M=5000\Delta t=2500/3$~kWh，$\eta_c=\eta_d=0.90$，与问题一保持同一套
母线侧充放电口径。注意平衡式中使用的是\textbf{风险修正后}的净负荷，因此
$\bar w$ 只是规划意义上的剩余量，\textbf{实际弃电量必须在执行层重新计算}。
$\bar c$ 与 $\bar w$ 均不收费，即$\bar w$ 允许"弃用已购电"，否则预测偏高的
时段会人为变成不可行。

按变量排列，模型 \eqref{eq:p2-model} 共 $6\times144+1=\mathbf{865}$ 个决策
变量，其中 $144$ 个为二元变量 $z_{n,t}$，其余为连续变量，故是\textbf{混合
整数线性规划}。结构矩阵与问题一一样只依赖时段划分，可\textbf{预先装配一次}，
此后每天只更新等式右端项，单次求解约 $46$~ms。

\subsection{实时执行模型：因果反馈规则}

执行层\textbf{只使用当天 $0{:}00$ 已冻结的计划、当前已观测的功率和当前储电量}，
不读取任何未来实际值。设使用储能前的电量盈余为

\begin{equation}
  b_{n,t}=g_{n,t}+v_{n,t}^{\mathrm{actual}}-\ell_{n,t}^{\mathrm{actual}} ,
  \label{eq:p2-surplus}
\end{equation}

$b>0$ 表示计划购电与光伏有剩余，$b<0$ 表示出现缺口。

\textbf{（1）有剩余时充电}，只利用本段已有的剩余电量，不为追赶参考计划在
负载已经缺电时机械充电：

\begin{equation}
  c_{n,t}^{\mathrm{actual}}
  =\min\Bigl\{(b_{n,t})_+,\ M,\
  \frac{E_{\max}-E_{n,t-1}^{\mathrm{actual}}}{\eta_c}\Bigr\} .
  \label{eq:p2-charge}
\end{equation}

\textbf{（2）有缺口时按储备线放电。}在 $0{:}00$ 即可算出当天的储备线

\begin{equation}
  R_{n,t}=E_{\min}+\rho\,\bigl(\bar E_{n,t}-E_{\min}\bigr),\qquad 0\le\rho\le1 ,
  \label{eq:p2-reserve}
\end{equation}

实际放电量为

\begin{equation}
  d_{n,t}^{\mathrm{actual}}
  =\min\Bigl\{(-b_{n,t})_+,\ M,\
  \eta_d\bigl(E_{n,t-1}^{\mathrm{actual}}-R_{n,t}\bigr)_+\Bigr\} .
  \label{eq:p2-discharge}
\end{equation}

$\rho=0$ 表示尽可能用现有储能补足当前缺口；$\rho=1$ 表示不主动放到当段
参考电量以下，为后续时段保留更多电量。注意\textbf{较高储备不一定更省钱}，
故 $\rho$ 同样交由标定决定。

\textbf{（3）紧急购电、弃电与真实电池状态。}

\begin{equation}
  r_{n,t}=\bigl(-b_{n,t}-d_{n,t}^{\mathrm{actual}}\bigr)_+,
  \qquad
  w_{n,t}^{\mathrm{actual}}=\bigl(b_{n,t}-c_{n,t}^{\mathrm{actual}}\bigr)_+ ,
  \label{eq:p2-residual}
\end{equation}

\begin{equation}
  E_{n,t}^{\mathrm{actual}}
  =E_{n,t-1}^{\mathrm{actual}}
  +\eta_c\,c_{n,t}^{\mathrm{actual}}
  -\frac{d_{n,t}^{\mathrm{actual}}}{\eta_d} .
  \label{eq:p2-state}
\end{equation}

该规则自动避免同时充放电，并保证实际逐段能量守恒：

\begin{equation}
  g_{n,t}+r_{n,t}+v_{n,t}^{\mathrm{actual}}+d_{n,t}^{\mathrm{actual}}
  =\ell_{n,t}^{\mathrm{actual}}+c_{n,t}^{\mathrm{actual}}
  +w_{n,t}^{\mathrm{actual}} .
  \label{eq:p2-actual-balance}
\end{equation}

$w^{\mathrm{actual}}$ 允许来自光伏，也允许来自已经付费的计划购电，因此不设置
"弃电量只能小于光伏电量"的限制。

\textbf{（4）跨日状态传递。}次日初始电量严格取当天\textbf{实际执行后}的日末
电量：

\begin{equation}
  E_{n+1,0}^{\mathrm{actual}}=E_{n,144}^{\mathrm{actual}} .
  \label{eq:p2-carry}
\end{equation}

不能用参考计划中的 $\bar E_{n,144}$ 替代。由式 \eqref{eq:p2-state} 对全天求和
可得状态累计恒等式

\begin{equation}
  E_{n,144}^{\mathrm{actual}}-E_{n,0}^{\mathrm{actual}}
  =\eta_c\sum_{t=1}^{144}c_{n,t}^{\mathrm{actual}}
  -\frac{1}{\eta_d}\sum_{t=1}^{144}d_{n,t}^{\mathrm{actual}} ,
  \label{eq:p2-accum}
\end{equation}

它是本文逐日校验的核心关系之一。只有当某日首尾电量恰好相同时，
$\sum_t d_{n,t}=0.81\sum_t c_{n,t}$ 才成立；问题二中绝大多数日子并不满足，
故\textbf{不能沿用问题一的这一关系}。

\subsection{参数标定：用过去连续区间的实际总费用选参}
\label{sec:p2-calib}

模型含三个需要选择的参数：风险分位数 $\alpha$、储备线系数 $\rho$ 与日末储备
代价 $\lambda$。本文采用如下\textbf{严格因果}的滚动标定：从正式区间第一天起，
每隔 $42$ 天重新标定一次；每次标定时，对参数网格中的每个组合，从
\textbf{该日之前}的 $35$ 天窗口起点出发，用主运行在\textbf{窗口起点日}
$0{:}00$ 的实际储电量作为窗口初值回放整个窗口，比较窗口内\textbf{包含
$5$ 倍紧急购电费的实际总费用}，取最小者。需说明的是，首次标定
（$2$ 月 $1$ 日）的窗口受数据起点 $1$ 月 $1$ 日限制，实际只有 $31$ 天；
其余 $7$ 次均为完整的 $35$ 天。参数网格为

\begin{equation}
  \alpha\in\{0.50,\ 0.60,\ 0.70,\ 0.80,\ 0.90\},\quad
  \rho\in\{0,\ 1\},\quad
  \lambda\in\{0,\ 0.60\} ,
  \label{eq:p2-grid}
\end{equation}

共 $5\times2\times2=20$ 个组合。标定所用的历史、回放窗口与参数一律不越过

\subsection{结果分析}

\subsubsection{预测误差如何转化为紧急购电成本}

图~\ref{fig:p2-forecast} 给出四个指定日期的净负荷预测、风险余量与实际净负荷。
三个层次的关系清晰可见：净负荷预测（虚线）给出基准，风险余量
$Q_{\alpha}$（橙色阴影）在预测之上叠加一段风险修正量，得到用于日前求解的
风险净负荷（橙实线），而实际净负荷（深蓝实线）则在其上下波动。

需要说明，$Q_{\alpha}$ 是历史误差的经验分位数，\textbf{并不保证为正}：正式
区间 $334\times144=48096$ 个时段中有 $1779$ 个（$3.7\%$）为负，最小值
$-30.9$~kWh、最大值 $241.1$~kWh。这些负值出现在误差分布整体偏负（长期被
高估）的时段，此时"分位数修正"正确地指示了\textbf{可以少买}——它与总体上
"风险余量抬高计划量"的方向并不矛盾，因为决定费用的始终是分位数本身，而不是
"加一个正数"这一形式。

关键在于\textbf{实际曲线落在风险净负荷之上的部分}。图~\ref{fig:p2-forecast}
用倒三角标出了发生紧急购电的时段，$9$ 月 $23$ 日出现了 $10$ 段紧急购电，
另外三个日期则全天为零。但逐时段核对可以发现，\textbf{超出风险净负荷只是
发生紧急购电的必要条件，而不是充分条件}：

\begin{itemize}
  \item $6$ 月 $21$ 日确实被风险净负荷\textbf{完整包住}（$144$ 段无一段超出）；
  \item $3$ 月 $20$ 日与 $12$ 月 $21$ 日分别有 $42$ 段与 $14$ 段超出风险净负荷，
        但最大超出仅 $85.2$~kWh 与 $80.4$~kWh，且都出现在储能尚有余量的时段，
        被电池吸收，故\textbf{全天无紧急购电}；
  \item $9$ 月 $23$ 日有 $68$ 段超出，最大超出 $137.8$~kWh，且\textbf{当日储能
        在 $20{:}30$ 已被放到下限 $1200$~kWh，并在其后约 $8$ 个时段钉在下限上}；
        电池一旦触底，其后每一段缺口都只能按 $5$ 倍电价补购。
\end{itemize}

这解释了 $9$ 月 $23$ 日晚间的 $10$ 段紧急购电：其中 $9$ 段的实际净负荷高于
风险净负荷，另 $1$ 段（$20{:}30$）的实际值甚至\textbf{低于}风险净负荷
$34.0$~kWh，却仍紧急购电 $784.9$~kWh——因为电池已无电可放。可见真正的触发
机制是\textbf{"实际净负荷超出风险余量的部分"与"储能剩余可放能力"两者之差}：
前者为正只是故事的开始，只有当储能无法再兜底时，才转化为 $5$ 倍电价的支出。
这三个日期的差别正在于此——$3$ 月 $20$ 日与 $12$ 月 $21$ 日的超出量小
（超幅超过 $50$~kWh 的时段各仅 $2$ 个），$9$ 月 $23$ 日则达 $19$ 个。

由此得到本文最重要的定性结论：\textbf{紧急购电成本来自"预测偏低"，而非
"预测不准"}——预测偏高只会造成弃电（无直接费用），预测偏低才会在储能耗尽时
触发 $5$ 倍电价。这也是选择\textbf{分位数}而非均值作为计划依据的根本原因。

\subsubsection{全年费用分解与对照策略}

图~\ref{fig:p2-yearly} 从全年尺度展示结果。
图~\ref{fig:p2-yearly}(a) 给出本文策略的逐月费用分解。月费用最高的三个月是
$12$ 月（$175.6$ 万元）、$7$ 月（$158.9$ 万元）与 $6$ 月（$155.6$ 万元），
最低的三个月是 $4$ 月（$96.4$ 万元）、$5$ 月（$100.5$ 万元）与 $10$ 月
（$111.8$ 万元），最高月约为最低月的 $1.8$ 倍。这一形态主要由负载与光伏的
季节错配决定：$12$ 月光伏出力全年最弱而负载处于高位，$6$--$7$ 月则因制冷
负荷抬高用电水平，而春季与初秋光伏尚可、负载适中，故费用最低。

值得注意的是\textbf{月度总费用的排序与紧急购电费的排序并不一致}：紧急购电费
在 $6$ 月达到 $190201$ 元，为全年最高，\textbf{占全年紧急购电费的 $28.7\%$}，
$12$ 月（$95615$ 元）与 $9$ 月（$84866$ 元）次之；而 $11$ 月的紧急购电费
仅 $5028$ 元、为全年最低，其总费用却仍排在第 $5$ 位。这说明\textbf{月费用
的高低主要仍由负载水平决定，紧急购电费则取决于预测偏差恰好与储能容量紧张
相遇的频率}，二者是两个不同的驱动因素。

为量化风险余量的价值，构造三组对照策略，全部使用\textbf{同一预测器、同一
实时执行规则、同一评价区间（$2$--$12$ 月共 $334$ 天）}，并各自单独标定参数：

\begin{itemize}
  \item \textbf{预测均值策略}：令 $\alpha=\text{None}$，即完全不加风险余量，
        直接用点预测制定日前计划，其余规则完全相同；
  \item \textbf{无储能策略}：仍提前制定购电计划、仍按 $5$ 倍价格补缺，但
        不启用储能，用于单独评价电池的价值；
  \item \textbf{事后理想策略}：用当天\textbf{实际}净负荷替换预测值求解同一
        日前 MILP，代表"完全预知当天净负荷"的费用参照。须注意它每天仍从
        主策略的实际日初储电量出发、且不要求日末保留电量，因此会把电池放到
        下限收手，是一个\textbf{不可执行的乐观下界}，而非可达方案。
\end{itemize}

表~\ref{tab:p2-strategy} 给出四者的费用对比。本文风险修正策略全年合计
$14021565$~元，较预测均值策略的 $15065121$~元节省 $1043556$~元、较无储能
策略的 $18555905$~元节省 $4534340$~元，分别相当于\textbf{本文策略费用的}
$7.44\%$ 与 $32.34\%$（与表~\ref{tab:p2-strategy} 末列同口径）。事后理想
策略为 $12082248$~元，比本文策略低 $1939317$~元（$13.8\%$）。但该值
\textbf{偏乐观}：理想策略每天直接动用主策略已按计划电价付过费的库存电量，
且不要求日末留存。若改为让理想方案自行传递跨日状态、并与主策略一样扣住日末
储电量，其费用为 $12251972$~元，差距收窄至 $12.6\%$。按这一\textbf{自洽口径}，
预测不确定性带来的不可避免代价约为 $12.6\%$（约 $177$ 万元），本文策略由此
仍有明确的改进空间。

更值得注意的是费用结构的变化：预测均值策略的\textbf{紧急购电费高达
$2867578$~元，是本文策略 $662827$~元的 $4.3$ 倍}，而其计划购电费反而更低
（$12197543$~元 对 $13358738$~元）。这正是"代价不对称"的直接体现——不加
风险余量时，日前计划买的电更少、看起来更省，但代价是运行时频繁触发 $5$ 倍
电价的紧急购电，总费用反而更高。\textbf{风险余量本质上是用"少量、分散、
可预期的计划购电溢价"替换"大量、集中、代价高昂的紧急购电"}。

同时应注意，四个策略的\textbf{期末储电量并不相同}（本文策略
$1687.8$~kWh，预测均值策略 $5957.1$~kWh，无储能策略 $6000.0$~kWh）。
期末储电量差异意味着库存并未被完全对等地消耗，因此本文同时报告该指标，
避免把"多消耗库存"误当作算法收益。

\subsubsection{标定结果对理论分析的验证}

表~\ref{tab:p2-calib} 给出 $8$ 次滚动标定的选中参数。结果非常集中：
$\alpha$ 在 $8$ 次标定中\textbf{全部落在 $0.70$--$0.90$ 之间}，其中
$0.80$ 出现 $6$ 次、$0.90$ 与 $0.70$ 各 $1$ 次。这一结果与
式 \eqref{eq:p2-critical} 的理论预测\textbf{高度吻合}：由 $5$ 倍紧急电价
导出的最优分位数恰为 $0.80$，而完全基于 $2025$ 年实际数据、按真实总费用
选出的参数也稳定落在 $0.80$ 附近。\textbf{理论推导与实际数据标定相互印证}，
这既支持了风险修正模型的合理性，也说明本文的 $80\%$ 分位数并非人为设定。

关于 $\lambda$，全部 $8$ 次标定都选择了 $\lambda=0.00$。这说明在
\textbf{$35$ 天窗口的实际总费用}这一评价口径下，日末储备惩罚并未带来净收益：
窗口内的回放已经包含了储备不足在后续日期引发的紧急购电代价，而由于电池容量
上限（$10800$~kWh）本身构成了自然的约束，额外的储备惩罚只会让模型在日末
保留过多电量、减少可用的调峰空间。因此本文最终报告的结果中 $\lambda=0$；
但需强调，\textbf{$\xi$ 项在模型中的存在是必要的}——它使得"是否保留储备"
成为一个由数据回答的问题，而不是一个未加检验的隐含假设。$\rho$ 的取值则
在 $0$ 与 $1$ 两个端点之间跳变（$6$ 次取 $0$、$2$ 次取 $1$，且两次取 $1$
分别出现在 $2$ 月与 $6$ 月），同样说明较高的储备线并不必然更省钱。

\subsubsection{弃用电量的成因}

全年弃用电量 $2704833.51$~kWh，占同期光伏发电量 $19068890.0$~kWh 的 $14.2\%$。
题目未对弃电设置惩罚或收益，故弃电不带来额外扣款，但它仍是日前计划与实时
运行之间偏差的\textbf{指示器}。逐时段分解显示弃电来自\textbf{两个性质不同}的
来源：$70.0\%$ 是光伏富余超出储能吸纳能力（储能受 $5000$~kW 功率上限与
$10800$~kWh 容量上限双重约束）；另 $30.0\%$ 发生在\textbf{光伏并无富余}的
时段，只能来自\textbf{已按计划电价付费、却因实际负载低于预期而用不掉的计划
购电量}，其当初购电成本 $544354$~元约占全年计划购电费的 $4.07\%$——即约三成
弃电是"按 $5$ 倍电价买保险"预付而未出险的保费。$\alpha$ 敏感性验证表明这一
取舍\textbf{经过权衡且最优}：$\alpha$ 由 $0.80$ 降至 $0.50$ 时弃电由 $2662.5$
降至 $1500.1$~MWh，但紧急购电量由 $179.8$ 猛增至 $642.9$~MWh，
\textbf{总费用反由 $1407.2$ 万元升至 $1513.1$ 万元}。此外，紧急购电负担在时间上
\textbf{高度集中}：$334$ 天中 $160$ 天发生紧急购电，而 $6$ 月 $1$ 日单日即占
全年紧急购电费的 $9.8\%$，说明它由少数连续多日的高压时段主导。成因分解的

    """对最优解做独立复核，返回问题清单（空列表 = 全部通过）。"""
    problems = []
    # 1) 逐段供需平衡（等式 + 显式弃光）
    resid = sol.g + (pv_kwh - sol.s) + sol.d - load_kwh - sol.c
    if np.abs(resid).max() > tol * max(1.0, load_kwh.max()):
        problems.append(f"供需平衡残差过大：{np.abs(resid).max():.3e}")

    if sol.s.min() < -tol: problems.append("弃光量为负")

    # 3) 充放电量限值 M = 2500/3 kWh

    Erec = [sol.E0]

    if abs(sol.E[-1] - sol.E0) > tol: problems.append("E144 != E0")

class ForecastParams:
    """近期加权历史预测的超参数（框架文档 3.2 节）。"""
    window: int = 15            # 回看窗口天数
    decay: float = 0.30         # 每 7 天的权重衰减因子
    weekday_only: bool = False  # 是否只用同一星期的历史
    name: str = "负荷"

# 在正式区间开始前选定并冻结的预测超参数，回放中不再调整。
LOAD_FORECAST = ForecastParams(window=15, decay=0.30, weekday_only=True, name="负荷")
PV_FORECAST   = ForecastParams(window=5,  decay=0.50, weekday_only=False, name="光伏")

def forecast_weights(n, fp):
    """返回第 n 天预测所用的 (历史日下标, 归一化权重)，只取 i < n。"""
    lo = max(0, n - fp.window)
    idx = np.arange(lo, n)
    if len(idx) == 0:
        return idx, np.zeros(0)
    w = fp.decay ** ((n - 1 - idx) / 7.0)
    if fp.weekday_only:
        same = np.array([weekday_of(i) == weekday_of(n) for i in idx])
        if same.any():
            w = w * same
    s = w.sum()
    if s <= 0:
        return idx, np.full(len(idx), 1.0 / len(idx))
    return idx, w / s

def build_error_table(LOAD, PV, fo):
    """预计算 eps[n, t] = N[n,t] - Nhat[n,t | 日期 < n]。

    这是"逐日向前预测后得到的误差"，不是模型在训练数据上的拟合残差。
    第 0 天无历史，记为 NaN 并永不使用。
    """
    eps = np.full((N_DAY, N), np.nan)
    for n in range(1, N_DAY):
        _, _, nhat = fo.energy(n)
        eps[n, :] = (LOAD[n, :] - PV[n, :]) * TAU - nhat
    return eps
\end{lstlisting}

\subsection{风险余量：误差的经验分位数}

\begin{lstlisting}[language=Python]
def risk_margin(eps, n, rp):
    """第 n 天各时段的风险余量 Q_{alpha,n,t}（kWh）。

    只取 n 之前已结束日期的误差；样本不足时合并相邻时段（±2 个 10 分钟），
    仍然只用过去数据，绝不回填同日或未来信息。
    """
    if rp.alpha is None or n == 0:
        return np.zeros(N)
    lo = max(0, n - rp.window)
    hist = eps[lo:n, :]
    hist = hist[~np.isnan(hist).all(axis=1)]
    k = hist.shape[0]
    if k >= rp.min_samples:
        return np.quantile(hist, rp.alpha, axis=0)
    if k >= 3:
        pooled = np.empty((k, N))
        for t in range(N):
            a, b = max(0, t - 2), min(N, t + 3)
            pooled[:, t] = hist[:, a:b].mean(axis=1)
        return np.quantile(pooled, rp.alpha, axis=0)
    return np.zeros(N)
\end{lstlisting}

def _precomp():
    """装配与日期无关的 MILP 结构，逐日只更换右端项，显著加速。"""

    # (2) 状态递推：     E_t - E_{t-1} - eta_c c_t + d_t/eta_d = 0   行 N..2N-1
    # (3) 充放电互斥：   c_i - M z_i <= 0,  d_i + M z_i <= M         2N 条

                         np.full(N, M_ENERGY), np.full(N, np.inf),

            "iE": iE, "iXi": iXi}

\subsection{实时执行规则}

执行层的核心特征是\textbf{因果性}：第 $t$ 段的动作只依赖 $t$ 时刻已经观测到
的实际负载、实际光伏与当前储电量，购电量 $g_t$ 由日前冻结、执行层无修改入口。

\begin{lstlisting}[language=Python]
def execute_day(plan_g, Ebar, l_act, v_act, e0, price, rp,
                rule="greedy", allow_storage=True):
    """实时执行：购电计划固定，储能按当前已观测情况因果响应。

    b_t = g_t + v_t - l_t 为使用储能前的电量盈余（kWh）。
    b > 0 用盈余充电（充不进去的弃用）；b < 0 在储备线之上放电，
    剩余缺口按 5 倍电价紧急购电。
    """
    for t in range(N):
        b = plan_g[t] + v_act[t] - l_act[t]
        R = E_MIN + rp.rho * (Ebar[t] - E_MIN)   # 0:00 即可算出的储备线

        if b > 0:
            bpos = min(b, M_ENERGY)
            c[t] = min(bpos, (E_MAX - Ep) / ETA)  # 盈余全部用于充电
            w[t] = b - c[t]                      # 充不进去的弃用（无收益）
        else:
            head = max(0.0, Ep - R)              # 电量不得低于储备线
            d[t] = min(-b, M_ENERGY, ETA * head)
            r[t] = max(0.0, -b - d[t])           # 仍缺的部分紧急购电

        Ep = Ep + ETA * c[t] - d[t] / ETA
        E[t] = Ep

    cost_plan = float(np.sum(price * plan_g))
    cost_emg = float(np.sum(5.0 * price * r))
    return DayExec(g=plan_g.copy(), c=c, d=d, r=r, w=w, E=E, E0=float(e0),
                   cost_plan=cost_plan, cost_emg=cost_emg)
\end{lstlisting}

\subsection{滚动参数标定}

标定在第 $n_0$ 天的 $0{:}00$ 进行，只用窗口内\textbf{已经结束}的历史日回放，
比较包含五倍紧急购电费的\textbf{实际总费用}，取最小者。

\begin{lstlisting}[language=Python]
class CalConfig:
    alphas: tuple = (0.50, 0.60, 0.70, 0.80, 0.90)
    rhos:   tuple = (0.0, 1.0)
    lams:   tuple = (0.0, 0.60)
    window: int = 35            # 标定回放窗口天数
    every:  int = 42            # 每隔多少天重新标定一次
    start:  int = REPORT_START  # 首次标定发生在正式区间第一天

                for a in self.alphas for r in self.rhos for l in self.lams]

def calibrate(sim, n0, e_at_window_start, cal):
    """在第 n0 天 0:00 用**此前**数据选择参数。"""
    lo = max(0, n0 - cal.window)
    best, best_cost = None, np.inf
    for rp in cal.grid():
        cost, _, _ = sim.replay(lo, n0, rp, e_at_window_start, cal.rule,
                                cal.allow_storage)
        if cost < best_cost - 1e-9:
            best_cost, best = cost, rp
    return best, rows

def run_strategy(sim, cal, verbose=True):
    """从 2025-01-01 的 6000 kWh 出发跑完整年，期间滚动标定参数。"""
    for n in range(N_DAY):
        if n >= cal.start and (n - cal.start) % cal.every == 0:
            params, _ = calibrate(
                sim, n, e_at_day_start[max(0, n - cal.window)], cal)
        rec = sim.run_day(n, params, e, cal.rule, cal.allow_storage)
        records.append(rec)
        e = rec.E_end                    # 跨日连续：次日 0:00 = 前日 24:00
        e_at_day_start[n + 1] = e
    return records, cal_rows

\subsection{六项强制检查的独立复核}

结果不依赖求解器自报的可行性，而是用\textbf{未四舍五入}的数据逐日独立复算。

\begin{lstlisting}[language=Python]
def validate_day(rec, tol=1e-6):
    """逐日复核实际运行结果，返回问题清单（空 = 通过）。框架文档 7.2 节。"""
    p = []
    ex, l, v = rec.exec, rec.l_act, rec.v_act

    # 1) 实际逐段供需平衡： g + r + v + d = l + c + w
    resid = ex.g + ex.r + v + ex.d - l - ex.c - ex.w
    scale = max(1.0, float(l.max()))
    if np.abs(resid).max() > tol * scale:
        p.append(f"供需平衡残差 {np.abs(resid).max():.3e} kWh")

    # 2) 物理边界：非负、不超 M、同段不同时充放电
    if ((ex.c > tol) & (ex.d > tol)).any():
        p.append("存在同时充放电的时段")

    # 3) 储电量区间（含日初，共 145 个状态点）
    Eseq = np.concatenate([[ex.E0], ex.E])
    if Eseq.min() < E_MIN - tol or Eseq.max() > E_MAX + tol:
        p.append("储电量越界")

    # 4) 状态累计（问题二不能套用问题一的 sum d = 0.81 sum c）
    lhs = ex.E[-1] - ex.E0
    rhs = ETA * ex.c.sum() - ex.d.sum() / ETA
    if abs(lhs - rhs) > tol * max(1.0, abs(rhs)):
        p.append(f"状态累计不符：dE={lhs:.6f} vs {rhs:.6f}")

    # 5) 费用一致性：弃电不退款，储备罚不混入实际账单
    cp = float(np.sum(_PRICE_REF * ex.g))
    ce = float(np.sum(5.0 * _PRICE_REF * ex.r))
    if abs(cp - ex.cost_plan) > tol * max(1.0, abs(cp)):
        p.append("计划费复算不符")
    if abs(ce - ex.cost_emg) > tol * max(1.0, abs(ce)):
        p.append("紧急费复算不符")

    # 6) 计划购电量在 0:00 后冻结（由架构保证，此处做存在性校验）
    if ex.g.shape != (N,) or ex.g.min() < -tol:
        p.append("计划购电量非法")
    return p
\end{lstlisting}

\subsection{时间转换：分段线性插值与十分钟电量}

十分钟区间的两端都与整点对齐，因此区间上插值曲线的积分恰好等于两端点的
算术平均乘区间长度，无需数值积分。

\begin{lstlisting}[language=Python]
def _interp_hour(A: np.ndarray, rel_min: float) -> float:
    # A[j] 是发布后 j 小时的预测功率（kW），节点间隔 60 min
    if rel_min <= 0.0:
        return float(A[0])
    if rel_min >= 1440.0:
        return float(A[24])
    j = int(rel_min // 60)
    th = (rel_min - 60.0 * j) / 60.0
    return float((1.0 - th) * A[j] + th * A[j + 1])

def forecast_energy_slots(fp, hi: int, n: int) -> np.ndarray:
    # 发布 hi 版对第 n 天各十分钟时段的光伏电量；发布前的时段为 NaN
    t0 = 36 * hi
    out = np.full(N, np.nan)
    A = fp.F[hi, n, :]
    rel0 = 60 * 6 * hi                     # 发布时刻相对 0:00 的分钟数
    for t in range(t0, N):
        ra = t * 10.0 - rel0
        rb = ra + 10.0
        out[t] = 0.5 * (_interp_hour(A, ra) + _interp_hour(A, rb)) * TAU
    return out
\end{lstlisting}

  \item 每行的储电量记录为当天 $24{:}00$ 的值，与次日 $0{:}00$ 的初值一致，
        跨日连续、不要求日循环。
\end{itemize}

\textbf{（2）内部结果文件（支撑材料 \texttt{06\_支撑材料/}）}

\begin{itemize}
  \item \texttt{p3\_detail.csv}：逐时段明细（$334\times144=48096$ 行），
        含电价、预测负载、$0{:}00$ 版光伏预报、净负荷预测、风险余量、风险净
        负荷、参考储电量、实际负载/光伏、初始计划购电量、最终购电量、上调量、
        下调量、实际充放电、紧急购电、弃电、期初期末储电量与三项时段费用；
  \item \texttt{p3\_daily.csv}：逐日汇总（$334$ 行），含全天电量、三项费用、
        储电量、调整提交次数与当日生效参数；
  \item \texttt{p3\_combinations.csv}：$8$ 种预报组合的全年汇总，即
        表~\ref{tab:p3-combo} 前八行的原始记录；
  \item \texttt{p3\_combo\_fees.csv}：在八种组合之外补入"重新优化但仍用
        $0{:}00$ 版本"的对照，共 $9$ 行的费用分解，即表~\ref{tab:p3-combo}
        与图~\ref{fig:p3-combo} 的费用口径原始记录；对照与退款口径的完整逐项
        指标见 \texttt{p3\_results.json}；
  \item \texttt{p3\_results.json}：正文全部汇总数字、七项检查结果与标定记录的
        机器可读版本。附表的 \ref{tab:p3-skill}--\ref{tab:p3-check} 由
        \texttt{p3\_tables.py} 直接读取该文件与 \texttt{p3\_detail.csv} 自动
        生成（\texttt{p3\_tables.tex}），\textbf{不做任何手工转录}；
  \item \texttt{p3\_cache/}：每个策略求解完成后立即落盘的单策略缓存，
        使得"重新生成论文表格"不必再跑一次上万次 MILP 的滚动标定，
        也保证了正文数字与首次求解结果严格一致。
\end{itemize}
