\begin{abstract}

微网通过在电价低谷时段为储能充电、在电价高峰时段放电，能够在满足小区负载
的前提下降低购电费用。本文围绕 2026 年 C 题，以混合整数线性规划为核心工具，
建立了微网日购电计划的确定性优化模型，并从效率参数、决策粒度、循环储电量等
多个口径对模型进行了灵敏度与稳健性分析。

针对\textbf{问题一}，电价与小区负载逐日相同、光伏出力给定单日预测，故只需
制定单日计划。我们将一天离散为 $144$ 个 $10$ 分钟时段（$\Delta t = 1/6$~h），
并统一以\textbf{电量}（kWh）为决策变量单位：$g_t$ 为\textbf{计划购电量}、
$c_t$ 为\textbf{充电量}、$d_t$ 为\textbf{放电量}、$s_t$ 为\textbf{弃光电量}、
$E_t$ 为时段末\textbf{储电量}（共 $145$ 个状态点 $E_0,\dots,E_{144}$），
$z_t \in \{0,1\}$ 为充放电\textbf{模式变量}。目标为全天购电费
$\min J = \sum_{t} p_t g_t$ 最小。约束包括三组：以显式弃光变量写成的供需
\textbf{等式}平衡 $g_t + (v_t - s_t) + d_t = \ell_t + c_t$；储能状态递推
$E_t = E_{t-1} + \eta_c c_t - d_t/\eta_d$（$\eta_c=\eta_d=0.90$，往返效率
$0.81$）；以及容量约束 $1200 \le E_t \le 10800$、日循环约束
$E_0 = E_{144} = 6000$~kWh 和互斥约束 $0 \le c_t \le Mz_t$、
$0 \le d_t \le M(1-z_t)$（$M = 2500/3$~kWh）。

模型以 $z_t$ 这一唯一整数变量构成 \textbf{MILP}，共 $864$ 个决策变量、
$289$ 条等式约束与 $288$ 条不等式约束，由 HiGHS 求解器求得\textbf{全局最优解}。
为独立验证，本文同时求解了去掉 $z_t$ 的 LP 松弛：其最优解中
\textbf{同时充放电的时段数为零}，且目标值与 MILP 完全一致（相差 $7.3\times
10^{-12}$ 元），故 LP 松弛的最优解本身已是完整模型的最优解——这一结论由程序
自动判定，而非依赖"电价为正"的先验假设。

主要结果：全天计划购电量 \textbf{59482.70~kWh}，全天购电费
\textbf{35126.95~元}，平均购电单价 $0.5905$~元/kWh。储能全天充电
$20740.67$~kWh、放电 $16799.94$~kWh，二者之比恰为往返效率
$0.81 = \eta_c\eta_d$；储电量全程处于 $[1200, 10800]$~kWh 且两端均被
\textbf{紧约束}触及，$0{:}00$ 与 $24{:}00$ 均为 $6000$~kWh。购电策略呈现
鲜明的"\textbf{谷充峰放}"特征：购电集中在 $0{:}00$--$6{:}00$ 与
$21{:}00$--$24{:}00$ 两个低电价时段，而在 $11{:}00$--$13{:}00$ 光伏出力超过
负载时购电量降为零，\textbf{全天弃光电量为零}。

灵敏度分析表明：若放电效率不计损耗，购电费降至 $33416.53$~元；若"$90\%$"
按往返效率理解并对称折算（$\eta_c=\eta_d=\sqrt{0.9}$），购电费为
$33801.50$~元，两种口径与主模型的差距均在 $5\%$ 以内；若允许储电量自由选择
日循环水平，最优循环点由给定的 $6000$~kWh 上移至 $8550$~kWh，购电费仅下降
$8.35$~元，说明附录给定初值已接近最优；若将充放电决策粗化为 $4$ 小时粒度，
购电费升至 $43648.06$~元（上升 $24.3\%$）并额外产生 $2293.67$~kWh 弃光，
说明 $10$ 分钟粒度的精细调度具有实质经济价值。基准对照显示，本模型较
"无储能"方案节省购电费 $12925.10$~元（$26.90\%$），较"无光伏无储能"方案
节省 $53192.41$~元（$60.23\%$），且通过储能消纳了无储能方案中原本会被弃掉的
$6247.96$~kWh 光伏电量。

\keywords{混合整数线性规划\quad 微网调度\quad 储能优化\quad 峰谷套利\quad 灵敏度分析}
\end{abstract}

% ---------------------------------------------------------------- 1 问题重述
\section{问题重述}

\subsection{问题背景}

微网是为解决光伏发电等分布式能源本地消纳、减少并网问题而快速发展起来的小型
发用电系统。出于经济方面的考虑，非孤岛式微网可在外部电网（以下简称外网）
电价较低或分布式能源有剩余电量的时间段为储能设备充电，并在外网电价较高的
时间段释放电能。

微网与外网调控的目标是：利用小区负载、光伏发电量和储能设备当前储电量等数据，
尽可能精准地给出微网的购电量和储能设备的充放电量，使微网提供的电力既满足
小区负载，又尽可能节省购电费用。

\subsection{问题提出}

\textbf{问题一}：若每天的电价和小区负载相同，同时给出光伏发电功率一天的预测
数据，要求微网提供的电能不低于小区负载，且储能设备在 $0{:}00$ 和 $24{:}00$
的储电量相同。需要在每天 $0{:}00$ 制定微网当天计划购电策略的数学模型；
根据附件 1 和附录 1 的数据给出具体策略，并以规定格式给出指定时段的购电量、
全天购电量与购电费，以及储能设备的充放电量与 $0{:}00$、$24{:}00$ 储电量，
完整策略保存至 \texttt{result1.xlsx}。

% ---------------------------------------------------------------- 2 问题分析
\section{问题分析}

\subsection{问题一分析}

问题一的关键在于识别其\textbf{确定性}与\textbf{单日性}。题目设定"每天的电价
和小区负载相同"，且光伏出力以"一天的预测数据"形式给出，这意味着各日的运行
条件完全一致，无需对全年 $365$ 天逐日建模，只需制定一个具有代表性的单日
计划即可；附录 5 中 \texttt{result1.xlsx} 仅含 $144$ 行数据，也印证了这一点。

在此设定下，微网面临的是一个\textbf{带储能的多时段能量调度问题}。其成本节约
来自两个相互关联的渠道：一是\textbf{峰谷套利}，即在低价时段多购电存入储能、
在高价时段放电替代购电；二是\textbf{光伏消纳}，即把光伏出力超过负载的盈余
电量存入储能，避免弃光，留待无光照时段使用。这两个渠道都要求决策必须
\textbf{跨时段协调}——某个时段多买一度电，会改变后续所有时段的可行域。
因此该问题不能逐时段贪心求解，必须整体优化。

从数学结构看，目标函数（购电费）关于决策变量线性，供需平衡、状态递推、
容量边界与互斥约束亦均为线性，故除模式变量 $z_t \in \{0,1\}$ 外，模型是一个
\textbf{线性规划（LP）}问题；引入 $z_t$ 后即为\textbf{混合整数线性规划
（MILP）}。由于 MILP 的连续松弛是 LP、其分支定界过程带有最优性下界判定，
解的最优性可以得到严格保证，无需担心陷入局部最优。

需要重点辨析的建模要点有四。其一，"微网提供的电能不可低于小区负载"虽然可以
写成不等式，但更清晰的做法是引入\textbf{显式弃光变量} $s_t$、把平衡写成
\textbf{等式} $g_t+(v_t-s_t)+d_t=\ell_t+c_t$：这样既能完整满足负载，又能
直接追踪富余光伏的去向，便于解释与校验。其二，储能的充电量在平衡式中属于
"消耗"而非"供给"，必须与购电、光伏放在同一式中联合考虑。其三，$0{:}00$ 与
$24{:}00$ 储电量相同构成\textbf{日循环约束}，使单日模型可逐日重复执行而不
产生储电量漂移；由递推式对全天求和还可推出 $\sum_t d_t = \eta_c\eta_d
\sum_t c_t$ 这一强校验关系。其四，同一时段\textbf{不能同时充电与放电}，这一
物理约束若不显式建模，在光伏免费富余或存在多重最优解时求解器仍可能返回
同时充放电的解，因此必须以二元变量 $z_t$ 强制互斥。

% ---------------------------------------------------------------- 3 模型假设
\section{模型假设}

\begin{enumerate}
  \item \textbf{数据准确假设}：附件 1 给出的电价、小区负载与光伏发电预测功率
        准确反映当天实际情况，不考虑预测误差（预测误差的影响留待问题三讨论）。
  \item \textbf{分段恒定假设}：每个 $10$ 分钟时段内，购电、充放电、负载与
        光伏功率均保持恒定，时段内的电量等于功率乘以时长 $\Delta t = 1/6$~h。
        供电保障对应这一离散模型。
  \item \textbf{母线侧计量假设}：充放电量均按\textbf{微网母线侧}口径计量——
        $c_t$ 为从微网送入储能设备的电量，$d_t$ 为储能设备实际向微网交付的
        电量；额定充放电功率也按同一侧解释。
  \item \textbf{储能理想假设}：储能设备的单程充放电效率恒为 $\eta_c=\eta_d
        = 0.90$（往返效率 $0.81$），不随充放电功率大小、储电量水平、环境温度
        或设备老化而变化；不存在自放电与漏电损失。
  \item \textbf{单向购电假设}：题目未给出售电价格，微网仅向外部电网购电，
        $g_t \ge 0$，不引入余电上网收益。
  \item \textbf{弃光可行假设}：光伏出力超过负载且储能无法完全吸纳时，允许
        弃光，$0 \le s_t \le v_t$，即富余光伏总有确定的去向。
  \item \textbf{不外加上网限值假设}：附录中 $5000$~kW 限制的是\textbf{储能
        设备}的充放电功率，本文不额外为微网向外部电网的购电功率设置上限。
  \item \textbf{无紧急购电假设}：问题一中计划购电能够得到完全执行，不存在
        因计划不足而触发的紧急购电（该情形在问题二中讨论）。
  \item \textbf{日循环假设}：储能设备在每个调度日结束时回到当日 $0{:}00$ 的
        储电量水平，即 $E_{144} = E_0$，从而该计划可以逐日重复执行。
  \item \textbf{忽略衰减假设}：不考虑储能设备充放电过程中的容量衰减与寿命
        损耗成本。
\end{enumerate}

% ---------------------------------------------------------------- 5 问题一
\section{问题一：单日计划购电优化模型}

\subsection{数据预处理与时段划分}

附件 1 共给出 $144$ 组数据，涵盖一天 $24$ 小时，故将一天等分为
$T = 144$ 个长度为 $\Delta t = 10\ \text{min} = 1/6\ \text{h}$ 的时段。

需要特别说明时段标签的对应关系：附件 1 的时间列为区间\textbf{结束时刻}
（首行 $0{:}10$、末行 $0{:}00{+}1$），其中 $0{:}00{+}1$ 按题目附录 2 的规定表示
当天 $24{:}00$。因此附件 1 的第 $t$ 行对应时段
$[(t-1)\Delta t,\ t\Delta t)$，即第 $t$ 时段为 $(t-1)\times 10$ 分钟至
$t \times 10$ 分钟，该行的电价与功率作为这一区间的代表值。

这一理解与"储能设备在 $0{:}00$ 和 $24{:}00$ 的储电量相同"的日循环约束相互
印证：只有末行的 $0{:}00{+}1$ 代表 $24{:}00$，$24{:}00$ 才是可约束的时刻。
需要指出，附件 5 中 \texttt{result1.xlsx} 的"计划购电量"表首段标签为
$0{:}10$--$0{:}20$、末段为 $0{:}00{+}1$--$0{:}10{+}1$，其末段已越过当天，
与正文要求的 $0{:}00$--$24{:}00$ 口径整体错位一格。本文统一采用正文口径，
在输出副本中将购电时间标签改写为 $0{:}00$--$0{:}10$ 至 $23{:}50$--$0{:}00{+}1$，
行序与模板一一对应，原始模板文件保持不变。若后续有题目勘误或补充说明，
应据此调整。

\textbf{单位换算}：附件 1 中电价为元/kWh，负载与光伏功率为 kW。为便于与题目
结果表逐项对应，本文不直接以功率作决策变量，而是先把负载与光伏换算为时段
电量，再以\textbf{电量}为决策变量单位：

\begin{equation}
  \ell_t = L_t\,\Delta t, \qquad v_t = V_t\,\Delta t .
  \label{eq:unit}
\end{equation}

图~\ref{fig:p1-profiles} 给出附件 1 三类输入数据的全天变化特征：电价呈明显的
双峰结构，早高峰位于 $7{:}30$--$10{:}00$、晚高峰位于 $17{:}00$--$21{:}00$，
最高电价 $1.3952$~元/kWh（出现在 $20{:}30$--$20{:}40$），而夜间低谷约
$0.42$~元/kWh、全天最低 $0.3713$~元/kWh（出现在 $5{:}30$--$5{:}40$），峰谷
价差达 $3.76$ 倍，为峰谷套利提供了充足空间；小区负载在 $8{:}00$--$18{:}00$
维持在 $5500$~kW 以上的高位，夜间回落至约 $3400$~kW；光伏出力呈标准钟形
分布，$4{:}30$ 前后开始发电，正午达到峰值 $7612.32$~kW，$19{:}20$ 后归零，
全天有 $55$ 个时段出力为零。三者共同决定了优化问题的基本格局。

需要强调，题目所说的"每天的电价相同"指的是\textbf{每天重复同一条电价曲线}，
而非一天内电价恒定。附件 1 的电价每 $10$ 分钟都有具体数值，故本文不作峰谷
电价粗化，直接在 $10$ 分钟粒度上建模。

\subsection{模型建立}

\subsubsection{决策变量}

对每个时段 $t = 1, 2, \dots, 144$，定义如下决策变量（前四个以电量 kWh 计）：

\begin{itemize}
  \item $g_t \ge 0$：从外网购入的电量（kWh）；
  \item $c_t \ge 0$：向储能设备输入的充电量（kWh）；
  \item $d_t \ge 0$：储能设备向微网输出的放电量（kWh）；
  \item $s_t \ge 0$：弃用的光伏电量（kWh）；
  \item $E_t$：第 $t$ 时段末的储电量（kWh），$t = 0, 1, \dots, 144$；
  \item $z_t \in \{0,1\}$：充放电模式变量，$z_t = 1$ 表示该时段允许充电、
        $z_t = 0$ 表示允许放电。
\end{itemize}

注意 $E_0$ 是 $0{:}00$ 电量、$E_{144}$ 是 $24{:}00$ 电量，因此储电量序列共有
$\mathbf{145}$ 个状态点。

\subsubsection{目标函数：全天购电费最小}

微网的购电费用仅来自从外网购入的电量，故目标为最小化全天购电费：

\begin{equation}
  \min\ J = \sum_{t=1}^{T} p_t\, g_t .
  \label{eq:objective}
\end{equation}

由于 $g_t$ 已经是电量（kWh），此处不再乘 $\Delta t$。应注意目标是购电
\textbf{费用}最低而非购电\textbf{总量}最低：低价充电带来的能量损耗可能使
全天购电量上升，但仍能降低总费用。

\subsubsection{约束条件}

\textbf{（1）供需平衡约束（等式加显式弃光）}

微网在第 $t$ 时段可用电量由外网购电、扣除弃光后的光伏出力与储能放电三部分
构成，须恰好等于小区负载耗电与储能充电之和：

\begin{equation}
  g_t + (v_t - s_t) + d_t = \ell_t + c_t, \qquad t = 1,2,\dots,T
  \label{eq:balance}
\end{equation}

\textbf{（2）光伏与购电的非负及弃光上界}

\begin{equation}
  g_t \ge 0, \qquad 0 \ \le\ s_t \ \le\ v_t, \qquad t = 1,2,\dots,T
  \label{eq:curtail}
\end{equation}

式 \eqref{eq:balance}--\eqref{eq:curtail} 完整满足负载，并通过显式弃光变量
处理多余光伏。相比把供电条件写成不等式 $g_t+v_t+d_t-c_t \ge \ell_t$，
等式加弃光变量的写法可以直接追踪富余电量的去向，更方便解释和检查。
$s_t$ 的上界取 $v_t$ 表明弃光量不可能超过光伏发电量本身。

\textbf{（3）储能电量递推约束}

第 $t$ 时段末的储电量由上一时段末的储电量、本时段的充电量与放电量决定：

\begin{equation}
  E_t = E_{t-1} + \eta_c\, c_t - \frac{d_t}{\eta_d},
  \qquad t = 1,2,\dots,T
  \label{eq:recursion}
\end{equation}

其中 $\eta_c = \eta_d = 0.90$。这里不能把充电项与放电项都乘以 $0.90$——
两者都是母线侧电量，但一个流入电池、一个流出电池：充入 $1$~kWh 电量，电池
内部增加 $0.9$~kWh；向微网放出 $1$~kWh 电量，电池内部需减少 $1/0.9$~kWh。
该设定对应储能\textbf{往返效率} $\eta_c\eta_d = 0.81$。当 $t = 1$ 时
$E_{t-1} = E_0$，即 $0{:}00$ 的初始储电量。

\textbf{（4）储电量运行区间约束}

为避免过度充电或放电，储电量须全程保持在给定区间内，$145$ 个状态点逐一受限：

\begin{equation}
  E_{\min} \ \le\ E_t \ \le\ E_{\max}, \qquad t = 0,1,\dots,T
  \label{eq:socbound}
\end{equation}

其中 $E_{\min} = 1200$~kWh，$E_{\max} = 10800$~kWh。

\textbf{（5）功率上限与充放电互斥约束}

受逆变器与电池倍率限制，单个 $10$ 分钟内最大充电量与最大放电量均为

\begin{equation}
  M = P_{\max}\,\Delta t = 5000 \times \frac{1}{6} = \frac{2500}{3}\ \text{kWh},
  \label{eq:M}
\end{equation}

并利用二元变量约束同一时段不能同时充放电：

\begin{equation}
  0 \ \le\ c_t \ \le\ M z_t, \qquad
  0 \ \le\ d_t \ \le\ M(1-z_t), \qquad
  z_t \in \{0,1\}, \qquad t = 1,2,\dots,T
  \label{eq:mutex}
\end{equation}

$z_t = 1$ 时允许充电、放电量被压为零；$z_t = 0$ 时允许放电、充电量被压为零；
两种模式下都可以令充放电量同时取零，表示待机。

\textbf{（6）日循环约束}

题目要求储能设备在 $0{:}00$ 与 $24{:}00$ 的储电量相同，结合附录 1 给出的
$2025$ 年 $1$ 月 $1$ 日 $0{:}00$ 电量为 $6000$~kWh，有：

\begin{equation}
  E_0 = E^{\mathrm{init}} = 6000, \qquad E_T = E_0
  \label{eq:cycle}
\end{equation}

该约束保证计划可逐日重复执行：若 $24{:}00$ 储电量与 $0{:}00$ 不同，则次日
初始条件将发生漂移，单日模型无法描述长期运行。同时它也使得模型无法通过
额外消耗初始库存来获取不公平的费用优势。

由状态递推式 \eqref{eq:recursion} 对全天求和，结合日循环条件
\eqref{eq:cycle}，可推出一个很有用的校验公式：

\begin{equation}
  \eta_c \sum_{t=1}^{T} c_t = \frac{1}{\eta_d}\sum_{t=1}^{T} d_t
  \quad\Longrightarrow\quad
  \sum_{t=1}^{T} d_t = \eta_c\eta_d \sum_{t=1}^{T} c_t = 0.81 \sum_{t=1}^{T} c_t .
  \label{eq:cycle-check}
\end{equation}

因此，日初日末储电量相同\textbf{并不意味着}表中的全天充电量等于全天放电量，
二者之比应恰为往返效率 $0.81$。

\subsubsection{完整模型}

综合以上各式，问题一的数学模型为：

\begin{equation}
\begin{aligned}
  \min_{g,\,c,\,d,\,s,\,E,\,z} \quad & J = \sum_{t=1}^{144} p_t\, g_t \\[2pt]
  \text{s.t.} \quad
  & g_t + (v_t - s_t) + d_t = \ell_t + c_t, && t = 1,\dots,144 \\
  & E_t = E_{t-1} + \eta_c c_t - \frac{d_t}{\eta_d}, && t = 1,\dots,144 \\
  & E_{\min} \le E_t \le E_{\max}, && t = 0,\dots,144 \\
  & 0 \le c_t \le M z_t, \quad 0 \le d_t \le M(1-z_t), && t = 1,\dots,144 \\
  & 0 \le s_t \le v_t, \quad g_t \ge 0, && t = 1,\dots,144 \\
  & z_t \in \{0,1\}, && t = 1,\dots,144 \\
  & E_0 = E_{144} = 6000
\end{aligned}
\label{eq:full-model}
\end{equation}

\subsubsection{模型类别：MILP 及其 LP 松弛}

模型 \eqref{eq:full-model} 中，目标函数与全部约束关于决策变量均为线性，
唯一的非线性来源是 $z_t \in \{0,1\}$ 这一整数要求，因此这是一个
\textbf{混合整数线性规划（MILP）}，可以直接表达充放电互斥，适合作问题一的
完整主模型。

按变量排列
$x = [\,g_{1:T},\ c_{1:T},\ d_{1:T},\ s_{1:T},\ E_{1:T}\,]^{\mathsf{T}}
\in \mathbb{R}^{5T}$，并记 $z = [z_1,\dots,z_T]^{\mathsf{T}}$，模型
\eqref{eq:full-model} 可写成如下标准形式：

\begin{equation}
  \min_{x,\,z}\ \bar{c}^{\mathsf{T}} x
  \quad \text{s.t.} \quad
  A_{\mathrm{eq}}\begin{bmatrix}x\\z\end{bmatrix} = b_{\mathrm{eq}}, \quad
  A_{\mathrm{ub}}\begin{bmatrix}x\\z\end{bmatrix} \le b_{\mathrm{ub}}, \quad
  l \le x \le u, \quad z \in \{0,1\}^{T}
  \label{eq:milp-standard}
\end{equation}

其中目标系数 $\bar{c}$ 仅在购电变量位置取 $p_t$；等式约束
$A_{\mathrm{eq}}$（共 $144+144+1 = 289$ 条）对应供需平衡
\eqref{eq:balance}、状态递推 \eqref{eq:recursion} 与日循环条件
\eqref{eq:cycle}；不等式约束 $A_{\mathrm{ub}}$（共 $288$ 条）对应互斥约束
\eqref{eq:mutex}；边界 $l,u$ 对应 \eqref{eq:curtail} 与 \eqref{eq:socbound}。
完整模型共 $5\times144 + 144 = \mathbf{864}$ 个决策变量、$289$ 条等式约束与
$288$ 条不等式约束，且所有非零系数均取自
$\{0, \pm1, \pm\eta_c, \pm 1/\eta_d\}$，不含任何非线性项。

\textbf{LP 松弛的作用。}去掉整数要求 $z_t \in \{0,1\}$（即令
$0 \le z_t \le 1$）、仅保留 $0 \le c_t, d_t \le M$，模型退化为一个普通的 LP。
该 LP 的最优值是 MILP 最优值的\textbf{下界}，可用于核对数据、检查约束并
提供费用下界的参照。更重要的是：\textbf{如果 LP 最优解本身不含同时充放电，
则它满足完整模型，便已经是 MILP 的最优解。}这一判定由程序自动完成——先求解
LP，统计 $c_t^*$ 与 $d_t^*$ 同时为正的时段数，再求解 MILP 与之比较。需要
强调的是，\textbf{不能仅凭电价为正就假定求解器一定不会返回同时充放电}：
存在免费光伏富余、多重最优解或数值退化时，LP 松弛仍可能给出物理上不可执行的
解。因此本文不依赖这一先验假设，而是以数值判定为准。

本模型在结构上还是一个\textbf{网络流型线性规划}：储能可视为一个连接各时段的
"水库"，$E_t$ 是水位，$c_t$ 与 $d_t$ 分别是入库与出库流量。求解器采用
HiGHS，其 LP 部分以并行对偶修正单纯形法为核心，MILP 部分以分支定界配合
割平面求解，问题规模（$864$ 变量）在该求解器下属小规模问题。

\subsection{模型求解}

\subsubsection{求解方法与算法}

本文使用 Python 科学计算栈中的 \texttt{scipy.optimize.milp} 接口调用
\textbf{HiGHS} 求解器（当前主流的开源 LP/MILP 求解器），以稀疏矩阵存储
约束系数，对 LP 松弛与完整 MILP 分别求解。求解参数为默认的 $10^{-7}$ 量级
可行性容差。

求解流程为：

\begin{enumerate}
  \item 读取附件 1 的电价、负载与光伏三类序列，校验时段标签严格递增、等间隔
        且恰好覆盖当天 $144$ 个时段，确保时段口径成立；
  \item 按式 \eqref{eq:unit} 将功率换算为时段电量，整理容量、功率、效率与
        日初电量等参数；
  \item 按 \eqref{eq:milp-standard} 装配目标向量、约束矩阵与变量边界，
        分别构造 LP 松弛与完整 MILP；
  \item 调用 HiGHS 求解，记录求解状态、目标值与最优性间隙；
  \item 对解进行独立复核（供需平衡、状态递推、物理边界、日循环、充放电互斥、
        费用复算），并判定 LP 松弛解是否已是 MILP 最优解；
  \item 由通过校验的解汇总论文表格、绘制策略图，并按统一时间标签写出
        \texttt{result1.xlsx}。
\end{enumerate}

\subsubsection{求解结果与 LP/MILP 一致性}

LP 松弛与完整 MILP 的求解结果如下：

\begin{itemize}
  \item \textbf{LP 松弛}：最优费用 $35126.9486$~元；最优解中
        $c_t^*$ 与 $d_t^*$ 同时为正的时段数为 $\mathbf{0}$；
  \item \textbf{完整 MILP}：最优费用 $35126.9486$~元，最优性间隙
        $0$（已证明全局最优）；最优解同样不含同时充放电。
\end{itemize}

两模型的目标值相差 $7.3\times10^{-12}$~元，仅为浮点舍入量级。由于 LP 松弛
的最优解本身不含同时充放电，它自动满足互斥约束 \eqref{eq:mutex}，因而也是
完整模型 \eqref{eq:full-model} 的最优解。\textbf{该结论由数值判定独立得到，
未使用"电价为正"这一先验假设。}本文后续所有结果均取自这一（同时是 LP 与
MILP 的）最优解。

\subsubsection{求解结果的校验}

为确保结果可信，对最优解独立复核了以下各项，\textbf{全部通过}：

\begin{enumerate}
  \item \textbf{时段完整性}：$144$ 个时段完整覆盖当天 $0{:}00$--$24{:}00$，
        首尾与四小时分组均无错位；附件 1 时间标签经校验为
        $\{10,20,\dots,1440\}$ 分钟且严格递增。
  \item \textbf{逐段供需平衡}：$\max_t\bigl|g_t+v_t-s_t+d_t-\ell_t-c_t\bigr|
        < 10^{-6}$~kWh。
  \item \textbf{状态递推}：由 $c^*,d^*$ 从 $E_0$ 出发独立累计递推得到的
        储电量序列与求解器返回的 $E^*$ 最大偏差小于 $10^{-6}$~kWh。
  \item \textbf{物理边界}：$E^*$ 全程落在 $[1200,10800]$~kWh 内；
        $c_t^*,\,d_t^* \le M = 2500/3$~kWh；$0 \le s_t^* \le v_t$；
        且不存在同时充放电的时段。
  \item \textbf{日循环}：$E_{144}^* = E_0^* = 6000$~kWh，且按式
        \eqref{eq:cycle-check} 校验 $\sum_t d_t^* = 0.81\sum_t c_t^*$
        （实测 $16799.94 / 20740.67 = 0.810000$）。
  \item \textbf{费用与汇总}：用未四舍五入的数据重新计算
        $\sum_t p_t g_t^*$，与求解器返回值一致；各分段汇总与全天明细一致。
\end{enumerate}

数值复核仅设置极小的浮点容差，\textbf{未通过删除负数、裁剪越界值或修改末段
结果的方式掩盖任何约束违背}。

\subsection{结果分析}

\subsubsection{购电策略的时序特征}

图~\ref{fig:p1-purchase} 给出全天逐时段的计划购电量与电价的对照关系。可以
清晰地看到购电行为被\textbf{严格地压缩到了低电价时段}：

\begin{itemize}
  \item 在 $0{:}00$--$6{:}00$ 的夜间低谷（电价约 $0.42$~元/kWh），购电量
        维持在 $3400$--$5500$~kW 当量的高位，其中 $0{:}00$--$1{:}40$ 因需
        同时供给负载和为储能充电而接近满载；
  \item 在 $5{:}30$--$5{:}40$ 电价降至全天最低（$0.3713$~元/kWh）时，购电量
        出现全天峰值，体现了模型对边际电价的精确响应；
  \item 在 $7{:}30$--$10{:}00$ 与 $17{:}00$--$21{:}00$ 两个电价高峰段
        （电价最高达 $1.3952$~元/kWh，约为低谷的 $3.76$ 倍），购电量被压至
        接近零，改由储能放电满足负载；
  \item 在 $11{:}00$--$13{:}00$ 光伏出力超过小区负载的时段，购电量\textbf{降为
        零}，微网完全由光伏供电并有盈余为储能充电。这正是表~\ref{tab:p1-buy}
        中 $10{:}00$、$14{:}00$、$20{:}00$ 三个时段购电量为零的原因，而
        $12{:}00$、$16{:}00$、$18{:}00$ 由于处在电价快速变化的爬坡段，
        仍保留了一部分购电。
\end{itemize}

这一策略正是"谷充峰放"的定量体现：模型把所有可推迟的购电需求都转移到了
电价最低的时段。用边际条件可以解释这一行为：忽略容量与功率限制时，在低价
时段购入 $1$~kWh 电量用于充电，未来只能向负载交付 $\eta_c\eta_d$~kWh，
故跨时段购电储能具有经济性的条件为 $p_{\text{低}}/\eta_c\eta_d <
p_{\text{高}}$。代入 $\eta_c\eta_d = 0.81$，只要峰谷价差超过约 $1.23$ 倍
即值得套利，而附件 1 的实际峰谷比达 $3.76$，套利空间充裕。实际充电时段
则由优化模型在综合考虑光伏富余、后续峰值价格、剩余容量与日末恢复电量后
自动确定。

扩大储能容量或放宽储电量运行区间，可望带来额外的经济效益。

\subsubsection{灵敏度分析}

题目只给出一个"充放电效率为 $90\%$"的参数，其在充电与放电两侧的分配方式
存在解释空间：可以是单程效率（$\eta_c=\eta_d=0.9$，往返 $0.81$），也可以是
往返效率（对称折算为 $\eta_c=\eta_d=\sqrt{0.9}\approx0.9487$，往返 $0.90$）。
此外，储能的日循环水平、充放电决策的时间粒度也均可能影响结论。为此设计
六组对照口径：

对表~\ref{tab:p1-sensitivity} 的分析可得以下结论：

\textbf{（1）效率约定影响有限，主要结论稳健。}若将 $90\%$ 的效率解释为往返
效率并对称折算（$\eta_c=\eta_d=\sqrt{0.9}$），购电费为 $33801.50$~元，较主
模型降低 $3.77\%$；若极端地假设放电无损（$\eta_c=0.90$，$\eta_d=1.00$），
购电费为 $33416.53$~元，降低 $4.87\%$。两者构成单程/往返两种解释下的费用
区间 $[33416.53,\ 35126.95]$~元，跨度不足 $5\%$。原因是放电效率越低，
储能放电时需额外多消耗的储存电量越多，越直接地削弱峰谷套利收益。\textbf{两
种口径下"谷充峰放"的策略结构与零弃光结论均不变}，说明主模型对效率参数的
分配方式不敏感。

\textbf{（2）给定的初始储电量接近最优循环水平。}若解除 $E_0 = 6000$~kWh 的
固定约束、仅要求日循环 $E_0 = E_{144}$，模型自动收敛到 $E_0 = 8550$~kWh，
购电费仅下降 $8.35$~元（$0.024\%$）。这说明附录 1 给定的 $6000$~kWh 已非常
接近成本最优的日循环工作点，无需大幅调整。该结果也验证了主模型采用
$E_0 = 6000$~kWh 的合理性：即使放开，最优解也不会显著偏离；同时它从反面
说明，把初始储电量当作可自由优化的资源只会带来不足万分之三的收益，不值得
为此偏离附录给定值。

\textbf{（3）决策粒度具有实质经济价值。}这是灵敏度分析中最显著的效应。当
充放电决策由 $10$ 分钟粗化为 $1$ 小时时，购电费上升 $4.68\%$ 并产生
$768.44$~kWh 弃光；粗化为 $4$ 小时时，购电费上升 $24.26\%$（达
$43648.06$~元），弃光量进一步增至 $2293.67$~kWh。原因是粗粒度下储能功率在
各时段内被迫恒定，无法跟踪电价与光伏的快速波动，峰谷套利的时机被显著钝化，
光伏盈余与储能充电能力也难以精确匹配，只能弃光。因此\textbf{采用 $10$ 分钟
的精细决策粒度是必要的}，这也从侧面说明题目要求以 $10$ 分钟为间隔给出购电量
是合理的。

\subsection{解的正确性独立复核}

\begin{lstlisting}[language=Python]
def validate(sol, df, var, tol=1e-6):
    """对最优解做独立复核，返回问题清单（空列表 = 全部通过）。"""
    problems = []
    # 1) 逐段供需平衡（等式 + 显式弃光）
    resid = sol.g + (pv_kwh - sol.s) + sol.d - load_kwh - sol.c
    if np.abs(resid).max() > tol * max(1.0, load_kwh.max()):
        problems.append(f"供需平衡残差过大：{np.abs(resid).max():.3e}")
    # 2) 弃光量非负且不超过光伏出力
    if sol.s.min() < -tol: problems.append("弃光量为负")
    if (sol.s - pv_kwh).max() > tol: problems.append("弃光量超过光伏可用出力")
    # 3) 充放电量限值 M = 2500/3 kWh
    if sol.c.max() > M_ENERGY + tol: problems.append("充电量越限")
    if sol.d.max() > M_ENERGY + tol: problems.append("放电量越限")
    # 4) 储电量上下界（145 个状态点）
    Eseq = np.concatenate([[sol.E0], sol.E])
    if Eseq.min() < E_MIN - tol: problems.append("储电量低于下界")
    if Eseq.max() > E_MAX + tol: problems.append("储电量高于上界")
    # 5) 状态递推自洽
    Erec = [sol.E0]
    for i in range(N):
        Erec.append(Erec[-1] + ec * sol.c[i] - sol.d[i] / ed)
    if np.abs(np.array(Erec[1:]) - sol.E).max() > tol:
        problems.append("储电量递推不自洽")
    # 6) 日循环：E_144 = E_0，且 sum(d) = eta_c*eta_d*sum(c)
    if abs(sol.E[-1] - sol.E0) > tol: problems.append("E144 != E0")
    if abs(sol.d.sum() - ec * ed * sol.c.sum()) > tol * max(1.0, sol.d.sum()):
        problems.append("sum(d) != eta_c*eta_d*sum(c)")
    # 7) 充放电互斥（题目未直接给出、需自证的物理约束）
    if ((sol.c > tol) & (sol.d > tol)).any():
        problems.append("存在区间同时充放电")
    # 8) 费用复算
    if abs(float(np.sum(price * sol.g)) - sol.obj) > tol * max(1.0, abs(sol.obj)):
        problems.append("目标函数复算不符")
    return problems
