\begin{abstract}
本文研究含光伏与储能的并网微网购电调度问题。针对确定性电价、负荷与光伏功率
变化、多时点光伏预报以及实时波动电价四种运行条件，建立由预测、风险修正、优化
调度和时序执行组成的统一模型。模型以购电费用最小为目标，并满足功率平衡、储能
状态递推、容量与功率边界及充放电互斥等约束。

问题一将一天划分为 $144$ 个 $10$ 分钟时段，构建单日混合整数线性规划模型。
HiGHS 求得的最优方案中，全天计划购电量为 $59482.70$~kWh，购电费为
$35126.95$~元，平均购电价格为 $0.5905$~元/kWh，全天弃光量为零。
两种线性规划松弛均得到 $35126.95$~元的最优费用，且均不存在同时充放电；
标准松弛解与混合整数解一致，由此验证了所得方案的全局最优性。与无储能方案和无光伏、
无储能方案相比，购电费用分别降低 $26.90\%$ 和 $60.23\%$。

问题二根据历史负荷与光伏数据建立日前预测模型，并以历史预测误差的经验分位数
修正净负荷预测。由紧急购电价格为常规电价 $5$ 倍的非对称成本关系，得到
$80\%$ 分位数的基准风险水平；随后通过连续时序仿真标定风险分位数、储备系数和
日末储备惩罚。以 2025 年 1 月为预热期，在 2 月 1 日至 12 月 31 日的 $334$ 天内，
计划购电量为 $21463158.37$~kWh，紧急购电量为 $140301.24$~kWh，总购电费为
$13939720.46$~元，其中紧急购电费占 $5.42\%$。该方案较预测均值策略和无储能
策略分别降低费用 $6.47\%$ 和 $24.73\%$。

问题三利用每日 $0{:}00$、$6{:}00$、$12{:}00$ 和 $18{:}00$ 发布的光伏预报，
建立分时滚动调整模型。模型区分初始计划购电量、调整后购电量和紧急购电量，并将
全天划分为四个六小时调整区间。对附件 3 的时间口径进行对齐检验后，采用以发布
时刻实际功率为左端点的分段线性插值。退款计费口径下，购电量的调整范围由
$Q_{0.7}$ 和 $Q_{0.9}$ 两个分位数确定。$334$ 天的时序仿真结果表明，总购电费为
$13{,}418{,}626.35$~元，其中计划费用、调整净额和紧急购电费用分别为
$12{,}583{,}676.62$、$562{,}013.56$ 和 $272{,}936.18$~元；相较于仅使用
$0{:}00$ 预报且不进行日内调整的策略，费用降低 $10.41\%$。预报组合分析显示，
$18{:}00$ 预报的边际贡献最大，而在已使用 $6{:}00$ 与 $18{:}00$ 预报时，加入
$12{:}00$ 预报可进一步降低费用 $11.44$ 万元。

问题四进一步将电价视为随日期和时段变化的随机量。价格预测参数在 1 月确定，并
在 2 月至 12 月保持不变；所采用的同星期加权模型权重为 $0.5/0.3/0.2$，三个
日内修正系数依次为 $1.0$、$0.75$ 和 $0.5$，评价期平均绝对误差为
$0.0446$~元/kWh。计划固定的 4-2 模型总费用为 $14740813.21$~元，允许日内调整
的 4-3 模型总费用为 $14153285.53$~元，后者降低 $3.99\%$。在当天价格完全已知的
参考条件下，4-3 费用为 $14075672.00$~元。结果表明，价格预测与日内调整能够共同降低
波动电价环境下的购电成本。

\keywords{混合整数线性规划\quad 微网调度\quad 储能优化\quad 峰谷套利\quad
风险分位数\quad 滚动决策\quad 灵敏度分析}
\end{abstract}

% ---------------------------------------------------------------- 1 问题重述
\section{问题重述}

\subsection{问题背景}

微网是为解决光伏发电等分布式能源本地消纳、减少并网问题而快速发展起来的小型
发用电系统。出于经济方面的考虑，非孤岛式微网可在外部电网（以下简称外网）
电价较低或分布式能源有剩余电量的时间段为储能设备充电，并在外网电价较高的
时间段释放电能。

微网与外网调控的目标是：利用小区负载、光伏发电量和储能设备当前储电量等数据，
尽可能精准地给出微网的购电量和储能设备的充放电量，使微网提供的电力既满足
小区负载，又尽可能节省购电费用。

\subsection{问题提出}

\textbf{问题一}：若每天的电价和小区负载相同，同时给出光伏发电功率一天的预测
数据，要求微网提供的电能不低于小区负载，且储能设备在 $0{:}00$ 和 $24{:}00$
的储电量相同。需要在每天 $0{:}00$ 制定微网当天计划购电策略的数学模型；
根据附件 1 和附录 1 的数据给出具体策略，并以规定格式给出指定时段的购电量、
全天购电量与购电费，以及储能设备的充放电量与 $0{:}00$、$24{:}00$ 储电量，
完整策略保存至 \texttt{result1.xlsx}。

\textbf{问题二}：若每天的电价相同，而小区负载和光伏发电功率随时间变化，且
微网提供的电能不可低于小区负载，如果低于负载需向外网紧急购电，其电价是交易
时刻电价的 $5$ 倍；除紧急购电费用外，其他时间段的购电费用均按计划购电量
计算。需要在每天 $0{:}00$ 制定当天的计划购电策略。根据附件 1 的电价和附件 2
的数据，给出表 3 中指定日期（2025.3.20、2025.6.21、2025.9.23、2025.12.21）
的结果，并以规定格式给出紧急购电结果，完整策略保存至 \texttt{result2.xlsx}。

\textbf{问题三}：每天 $0{:}00$、$6{:}00$、$12{:}00$ 和 $18{:}00$ 可获得未来
$24$ 小时整点的光伏发电功率预报。微网先依据 $0{:}00$ 预报制定当天计划购电
策略，并可依据其余时刻的新预报调整购电量。计划购电量高于调整购电量的部分按
交易时刻电价的 $50\%$ 收取违约费；调整购电量高于计划购电量的部分按交易时刻
电价的 $1.5$ 倍计费。总购电费用包括计划购电费、紧急购电费与调整相关费用。
需要建立相应的购电策略模型，给出四个指定日期的结果，将完整策略保存至
\texttt{result3.xlsx}，并分析其他时刻预报的引入价值。

\textbf{问题四}：外网电价改为实时波动。基于附件 2 的负载与光伏实际值、附件 3
的光伏预报和附件 4 的分时电价，在波动电价条件下重新计算问题二和问题三，给出
相应的购电策略与计算结果，并将完整策略分别保存至 \texttt{result4-2.xlsx} 和
\texttt{result4-3.xlsx}。

% ---------------------------------------------------------------- 2 问题分析
\section{问题分析}

四个问题采用相同的储能状态、能量平衡与效率约束，主要区别在于决策时可获得的
信息以及购电费用的计算规则。下面分别分析各问题的建模重点。

\subsection{问题一分析}

问题一中，各日采用相同的电价、负荷和光伏预测曲线，因此可用一个完整日的调度
方案表示重复运行策略。按照 $10$ 分钟间隔离散后，模型包含 $144$ 个决策时段。

储能通过低价时段充电、高价时段放电实现跨时段能量转移，同时吸收光伏富余电量。
任一时段的充放电决策都会改变后续储能状态，因而需要对全天统一优化。目标函数、
能量平衡、状态递推和运行边界均为线性关系；加入充放电模式变量
$z_t\in\{0,1\}$ 后，模型构成混合整数线性规划。

模型设置弃光变量，将供需关系写为等式；充电量计入用电侧，购电、光伏和放电量
计入供电侧。日循环约束 $E_{144}=E_0$ 保证方案可以逐日重复，并给出
$\sum_t d_t=\eta_c\eta_d\sum_t c_t$ 的状态一致性关系。二元变量用于约束同一时段
的充电和放电状态。

\subsection{问题二分析}

问题二需要同时处理日前预测、非对称购电成本和跨日储能状态。

制定第 $n$ 天计划时，当天的实际负荷和光伏功率尚未获得。因此，点预测和误差
分位数均由第 $n$ 天以前的数据计算，形成符合信息时序的日前预测结果。

计划购电每增加 $1$~kWh 产生费用 $p$，而计划不足的边际期望费用为
$5p\Pr(N>g)$。令两者相等可得 $F_N(g)=0.8$，因此以净负荷预测误差的
$80\%$ 分位数作为风险余量的理论基准。考虑储能的跨时段耦合后，再通过连续运行
费用对分位数水平进行标定。

跨日运行时，第 $n+1$ 天的初始储电量取第 $n$ 天执行后的末值。相应的状态校验采用
$\Delta E=\eta_c\sum_t c_t-\eta_d^{-1}\sum_t d_t$。为控制单日优化对期末储能的
消耗，目标函数中加入日末储备软约束 $\lambda\xi$；该项用于策略制定，不计入实际
购电费用。

据此，问题二采用“预测—风险修正—日前优化—实时执行—跨日更新”的建模流程，
并以包含紧急购电费用的实际总费用评价策略。

\subsection{问题三分析}

问题三允许根据日内新增预报调整购电计划，需要协调预报发布时间、调整范围和费用
结算方式。

每天共有四个预报版本，各自覆盖发布时刻以后 $24$ 个整点。数据处理时同时记录
发布时间和目标时间，并对缺少的发布时刻功率设置基于已观测数据的左端点。不同
预报版本的效果最终由连续运行费用评价。

问题三的调整价格改变了风险分位数。按照退款计费口径，增加 $1$~kWh 购电量的
成本为 $1.5p$，减少 $1$~kWh 购电量的违约成本为 $0.5p$。比较调整成本与
$5p\Pr(N>x)$ 的期望紧急购电成本，可得
$$
x^*=\operatorname{clip}\bigl(g^0,\ Q_{0.7}(N),\ Q_{0.9}(N)\bigr),
$$
其中 $[Q_{0.7},Q_{0.9}]$ 定义为计划保持区间：初始计划位于该区间时保持原值，
低于下界时增加至 $Q_{0.7}$，高于上界时减少至 $Q_{0.9}$。该关系与库存管理中的
临界比规则一致\cite{ref:newsvendor}。不退款计费口径下，调减不产生费用优势，模型
仅保留 $Q_{0.7}$ 的增加购电阈值。考虑储能耦合后，实际分位数参数通过连续时序
仿真标定。

为明确多次调整的结算对象，本文将全天划分为四个六小时调整区间。每个区间仅在
起始时刻提交一次调整量，每个十分钟时段均相对于其初始计划量结算；后续区间的
优化结果用于储能状态规划，达到相应发布时刻后再正式提交。

在此基础上建立多时点预报驱动的滚动购电模型，并对三个新增预报时刻形成的八种
组合分别进行全年时序仿真。另设置仅更新系统状态而沿用 $0{:}00$ 预报的参考策略，
用于分析新增预报信息与滚动优化对费用变化的贡献。

% ---------------------------------------------------------------- 3 模型假设
\section{模型假设}

\begin{enumerate}
  \item \textbf{数据准确假设}：附件 1 的电价、小区负载与光伏功率准确反映实际，
        不计预测误差（其影响留待问题三）。
  \item \textbf{分段恒定假设}：每个 $10$ 分钟时段内各功率恒定，时段电量等于功率
        乘以 $\Delta t = 1/6$~h；供电保障对应这一离散模型。
  \item \textbf{母线侧计量假设}：$c_t$ 为微网送入储能的电量、$d_t$ 为储能向微网
        交付的电量，均按\textbf{微网母线侧}口径计量，额定功率同侧解释。
  \item \textbf{储能理想假设}：单程效率恒为 $\eta_c=\eta_d=0.90$（往返 $0.81$），
        不随功率、储电量、温度或设备老化变化，无自放电与漏电损失。
  \item \textbf{单向购电假设}：题目未给出售电价格，$g_t \ge 0$，不计余电上网收益。
  \item \textbf{弃光可行假设}：光伏出力超过负载且储能无法完全吸纳时允许弃光，
        $0 \le s_t \le v_t$，富余光伏总有确定去向。
  \item \textbf{不外加上网限值假设}：附录中 $5000$~kW 限制的是\textbf{储能设备}
        的充放电功率，本文不另设微网购电功率上限。
  \item \textbf{无紧急购电假设}：问题一中计划购电得到完全执行，不触发因计划
        不足而生的紧急购电（该情形在问题二中讨论）。
  \item \textbf{日循环假设}：储能每日回到当日 $0{:}00$ 的水平，即 $E_{144}=E_0$，
        该计划可逐日重复执行。
  \item \textbf{忽略衰减假设}：不计容量衰减与寿命损耗成本。
\end{enumerate}

问题二改用以下假设（与问题一冲突处以本节为准）：

\begin{enumerate}
  \setcounter{enumi}{10}
  \item \textbf{电价逐日重复假设}：附件 1 的日内电价在 2025 年每天重复生效，
        不使用附件 4 的波动电价（留待问题四）。
  \item \textbf{实际值可观测假设}：当天运行时，执行层对负载与光伏作\textbf{段内
        实时测量}，本时段的充放电与紧急购电由本时段的实际值决定（理想即时
        响应、无控制滞后）；$10$ 分钟仅作为汇总与记账步长，时段末读数用于该
        时段的电量与费用结算。问题二、三、四共用同一执行层，本假设一致适用。
  \item \textbf{预测信息受限假设}：$0{:}00$ 制定计划时只能使用当天之前的负载
        与光伏实际值、已知的日内电价、日期与星期，以及当前实际储电量；当天
        实际曲线与附件 3 的外部光伏预报均不可使用。
  \item \textbf{计划购电量冻结假设}：$g_{n,t}$ 一经 $0{:}00$ 确定便不再修改，
        不足部分只能按 $5$ 倍电价紧急补购，无计划调整交易（留待问题三）。
  \item \textbf{紧急购电不退款假设}：已按计划购入的电量无论用完与否均全额收费，
        用不完的部分可转为充电，其余按无收益弃用处理，即\textbf{允许弃用已购电}。
  \item \textbf{储备惩罚不计入账单假设}：软惩罚项 $\lambda\xi_n$ 只用于制定策略，
        \textbf{不计入实际上报的购电费}。
\end{enumerate}

\subsection{模型建立}

\subsubsection{决策变量}

对每个时段 $t = 1, 2, \dots, 144$，定义如下决策变量（前四个以电量 kWh 计）：

\begin{itemize}
  \item $g_t \ge 0$：从外网购入的电量（kWh）；
  \item $c_t \ge 0$：向储能设备输入的充电量（kWh）；
  \item $d_t \ge 0$：储能设备向微网输出的放电量（kWh）；
  \item $s_t \ge 0$：弃用的光伏电量（kWh）；
  \item $E_t$：第 $t$ 时段末的储电量（kWh），$t = 0, 1, \dots, 144$；
  \item $z_t \in \{0,1\}$：充放电模式变量，$z_t = 1$ 表示该时段允许充电、
        $z_t = 0$ 表示允许放电。
\end{itemize}

注意 $E_0$ 是 $0{:}00$ 电量、$E_{144}$ 是 $24{:}00$ 电量，因此储电量序列共有
$\mathbf{145}$ 个状态点。

\subsubsection{目标函数：全天购电费最小}

微网的购电费用仅来自从外网购入的电量，故目标为最小化全天购电费：

\begin{equation}
  \min\ J = \sum_{t=1}^{T} p_t\, g_t .
  \label{eq:objective}
\end{equation}

由于 $g_t$ 的单位为 kWh，目标函数中无需再乘 $\Delta t$。储能能量损耗可能增加
购电总量，但低价充电、高价放电仍可降低购电费用。

\subsubsection{约束条件}

\textbf{（1）供需平衡约束（等式加显式弃光）}

微网在第 $t$ 时段可用电量由外网购电、扣除弃光后的光伏出力与储能放电三部分
构成，须恰好等于小区负载耗电与储能充电之和：

\begin{equation}
  g_t + (v_t - s_t) + d_t = \ell_t + c_t, \qquad t = 1,2,\dots,T
  \label{eq:balance}
\end{equation}

\textbf{（2）光伏与购电的非负及弃光上界}

\begin{equation}
  g_t \ge 0, \qquad 0 \ \le\ s_t \ \le\ v_t, \qquad t = 1,2,\dots,T
  \label{eq:curtail}
\end{equation}

式 \eqref{eq:balance}--\eqref{eq:curtail} 以显式弃光变量处理光伏富余，并可直接
统计其电量；约束 $s_t\le v_t$ 保证弃光量不超过光伏发电量。

\textbf{（3）储能电量递推约束}

第 $t$ 时段末的储电量由上一时段末的储电量、本时段的充电量与放电量决定：

\begin{equation}
  E_t = E_{t-1} + \eta_c\, c_t - \frac{d_t}{\eta_d},
  \qquad t = 1,2,\dots,T
  \label{eq:recursion}
\end{equation}

其中 $\eta_c = \eta_d = 0.90$。按照母线侧计量口径，充入 $1$~kWh 电量使储能
增加 $0.9$~kWh，向微网输出 $1$~kWh 电量使储能减少 $1/0.9$~kWh。
该设定对应储能\textbf{往返效率} $\eta_c\eta_d = 0.81$。当 $t = 1$ 时
$E_{t-1} = E_0$，即 $0{:}00$ 的初始储电量。

\textbf{（4）储电量运行区间约束}

为避免过度充电或放电，储电量须全程保持在给定区间内，$145$ 个状态点逐一受限：

\begin{equation}
  E_{\min} \ \le\ E_t \ \le\ E_{\max}, \qquad t = 0,1,\dots,T
  \label{eq:socbound}
\end{equation}

其中 $E_{\min} = 1200$~kWh，$E_{\max} = 10800$~kWh。

\textbf{（5）功率上限与充放电互斥约束}

受逆变器与电池倍率限制，单个 $10$ 分钟内最大充电量与最大放电量均为

\begin{equation}
  M = P_{\max}\,\Delta t = 5000 \times \frac{1}{6} = \frac{2500}{3}\ \text{kWh},
  \label{eq:M}
\end{equation}

并利用二元变量约束同一时段不能同时充放电：

\begin{equation}
  0 \ \le\ c_t \ \le\ M z_t, \qquad
  0 \ \le\ d_t \ \le\ M(1-z_t), \qquad
  z_t \in \{0,1\}, \qquad t = 1,2,\dots,T
  \label{eq:mutex}
\end{equation}

$z_t = 1$ 时允许充电、放电量被压为零；$z_t = 0$ 时允许放电、充电量被压为零；
两种模式下都可以令充放电量同时取零，表示待机。

\textbf{（6）日循环约束}

题目要求储能设备在 $0{:}00$ 与 $24{:}00$ 的储电量相同，结合附录 1 给出的
$2025$ 年 $1$ 月 $1$ 日 $0{:}00$ 电量为 $6000$~kWh，有：

\begin{equation}
  E_0 = E^{\mathrm{init}} = 6000, \qquad E_T = E_0
  \label{eq:cycle}
\end{equation}

该约束使日末储电量恢复至日初水平，从而形成可逐日重复的运行方案。

对状态递推式 \eqref{eq:recursion} 求和并结合日循环条件 \eqref{eq:cycle}，得到

\begin{equation}
  \eta_c \sum_{t=1}^{T} c_t = \frac{1}{\eta_d}\sum_{t=1}^{T} d_t
  \quad\Longrightarrow\quad
  \sum_{t=1}^{T} d_t = \eta_c\eta_d \sum_{t=1}^{T} c_t = 0.81 \sum_{t=1}^{T} c_t .
  \label{eq:cycle-check}
\end{equation}

因此，全天放电量与充电量之比应为往返效率 $0.81$。

\subsubsection{完整模型}

综合以上各式，问题一的数学模型为：

\begin{equation}
\begin{aligned}
  \min_{g,\,c,\,d,\,s,\,E,\,z} \quad & J = \sum_{t=1}^{144} p_t\, g_t \\[2pt]
  \text{s.t.} \quad
  & g_t + (v_t - s_t) + d_t = \ell_t + c_t, && t = 1,\dots,144 \\
  & E_t = E_{t-1} + \eta_c c_t - \frac{d_t}{\eta_d}, && t = 1,\dots,144 \\
  & E_{\min} \le E_t \le E_{\max}, && t = 0,\dots,144 \\
  & 0 \le c_t \le M z_t, \quad 0 \le d_t \le M(1-z_t), && t = 1,\dots,144 \\
  & 0 \le s_t \le v_t, \quad g_t \ge 0, && t = 1,\dots,144 \\
  & z_t \in \{0,1\}, && t = 1,\dots,144 \\
  & E_0 = E_{144} = 6000
\end{aligned}
\label{eq:full-model}
\end{equation}

\subsubsection{模型类别：MILP 及其 LP 松弛}

模型 \eqref{eq:full-model} 中目标函数与全部约束关于决策变量均为线性，唯一的
非线性来源是 $z_t \in \{0,1\}$ 这一整数要求，因此它是一个\textbf{混合整数线性
规划（MILP）}。按变量排列
$x=[g_{1:T},c_{1:T},d_{1:T},s_{1:T},E_{1:T}]^{\mathsf T}\in\mathbb R^{5T}$、
$z=[z_1,\dots,z_T]^{\mathsf T}$，可写成标准形式
$\min_{x,z}\bar c^{\mathsf T}x$ \ s.t.\ $A_{\mathrm{eq}}[x;z]=b_{\mathrm{eq}}$，
$A_{\mathrm{ub}}[x;z]\le b_{\mathrm{ub}}$，$l\le x\le u$，$z\in\{0,1\}^T$：
共 $\mathbf{864}$ 个决策变量（$5\times144+144$）、$289$ 条等式约束（供需平衡、
状态递推与日循环）与 $288$ 条不等式约束（互斥约束）。连续变量约束中的系数主要
由 $0,\pm1,\pm\eta_c,\pm1/\eta_d$ 构成，充放电模式约束另含常数 $M$。储能状态
变量连接相邻时段，使模型具有时序网络流结构。

程序设置两种线性规划下界：LP1 直接删除模式变量及互斥约束，包含 $720$ 个变量；
LP2 保留互斥约束但放宽为 $0\le z_t\le1$，包含 $864$ 个变量。完整 MILP 也
包含 $864$ 个变量。理论上有 $J_{\mathrm{LP1}}\le J_{\mathrm{LP2}}\le
J_{\mathrm{MILP}}$。程序分别求解三者，并检查两种松弛解的充放电互斥性。
其中 $M=5000\times(1/6)=833.33$~kWh，为单个十分钟时段的最大充放电量。
\subsection{模型求解}

\subsubsection{求解方法与算法}

本文使用 Python 科学计算栈中的 \texttt{scipy.optimize.milp} 接口调用
\textbf{HiGHS} 求解器（当前主流的开源 LP/MILP 求解器），以稀疏矩阵存储
约束系数，对两种 LP 松弛与完整 MILP 分别求解。求解参数为默认的 $10^{-7}$ 量级
可行性容差。

求解流程为：

\begin{enumerate}
  \item 读取附件 1 的电价、负载与光伏三类序列，校验时段标签严格递增、等间隔
        且恰好覆盖当天 $144$ 个时段，确保时段口径成立；
  \item 按式 \eqref{eq:unit} 将功率换算为时段电量，整理容量、功率、效率与
        日初电量等参数；
  \item 按上一小节的矩阵形式装配目标向量、约束矩阵与变量边界，
        分别构造 LP1 结构松弛、LP2 标准松弛与完整 MILP；
  \item 调用 HiGHS 求解，记录求解状态、目标值与最优性间隙；
  \item 对解进行独立复核（供需平衡、状态递推、物理边界、日循环、充放电互斥、
        费用复算），并判定 LP 松弛解是否已是 MILP 最优解；
  \item 由通过校验的解汇总论文表格、绘制策略图，并按统一时间标签写出
        \texttt{result1.xlsx}。
\end{enumerate}

\subsubsection{求解结果与 LP/MILP 一致性}

两种 LP 松弛与完整 MILP 的求解结果如下：

\begin{itemize}
  \item \textbf{LP1 结构松弛}：最优费用 $35126.9486$~元；同时充放电时段数为 $0$；
  \item \textbf{LP2 标准松弛}：最优费用 $35126.9486$~元；同时充放电时段数为 $0$；
  \item \textbf{完整 MILP}：最优费用 $35126.9486$~元，最优性间隙
        $0$（已证明全局最优）；最优解同样不含同时充放电。
\end{itemize}

三者的最优费用在数值精度内一致。LP2 与 MILP 的逐段解一致；LP1 因退化最优解，
有 $2$ 个时段的决策量与 MILP 不同，但同样满足互斥约束。由两侧一致的目标值可知
MILP 已达到线性规划下界。后续结果采用完整 MILP 的解。

\subsection{基准对照与灵敏度分析}
\label{sec:sensitivity}

为量化储能与光伏的经济价值，本文构造"光伏供电、缺口直接外购、电池保持不动"
的基准方案（它是原问题的一个可行解，故给出同一口径下的费用上界）；针对题目
只给出一个"充放电效率 $90\%$"、其单程/往返分配方式存在解释空间的情况，又设计
了效率分配、日循环水平与决策粒度共六组对照口径。两组对照的完整数据与逐项
推理见附录~\ref{app:extra}，正文只保留结论。

\begin{enumerate}
  \item \textbf{储能的综合作用。}配置储能后全天购电费由 $48052.05$~元
        降至 $35126.95$~元，\textbf{节省 $12925.10$~元（降幅 $26.90\%$）}；
        较"无光伏无储能"方案节省 $53192.41$~元（$60.23\%$）。含储能方案的
        购电量反而更少（$59482.70$ 对 $61789.94$~kWh），因为它把无储能时
        被迫弃掉的 $6247.96$~kWh 光伏盈余转移到了无光照时段，
        \textbf{提升了光伏本地消纳率}。
  \item \textbf{效率参数的影响。}单程与往返两种解释构成购电费
        区间 $[33416.53,\ 35126.95]$~元，跨度不足 $5\%$；两种口径下"谷充峰放"
        的策略结构与零弃光结论均不变。
  \item \textbf{决策粒度的影响。}决策由 $10$ 分钟粗化为 $1$ 小时时，
        购电费上升 $4.68\%$ 并产生 $768.44$~kWh 弃光；粗化为 $4$ 小时时上升
        $24.26\%$（$43648.06$~元），弃光增至 $2293.67$~kWh。因此采用
        $10$ 分钟粒度能够更充分地利用电价和光伏出力的时段差异。
  \item \textbf{给定的初始储电量已接近最优循环水平。}解除 $E_0=6000$~kWh 的
        固定约束后模型收敛到 $E_0=8550$~kWh，购电费仅下降 $8.35$~元
        （$0.024\%$），无需为此偏离题目给定值。
\end{enumerate}

\section{问题二：预测驱动的滚动日前计划与实时执行模型}

\subsection{问题二的建模特征}

问题二放宽了问题一的确定性设定：\textbf{电价仍逐日相同}（重复使用附件 1 的
日内曲线），但\textbf{小区负载与光伏出力改为附件 2 给出的全年实际值}，且
\textbf{计划购电不足时须按交易时刻电价的 $5$ 倍紧急补购}。据此，模型需要
处理以下三项特征：

\begin{enumerate}
  \item \textbf{信息约束}：每天 $0{:}00$ 制定计划时，当天的负载与光伏实际值
        尚未发生，计划只能依据此前历史预测；
  \item \textbf{代价不对称}：少买需要按 $5$ 倍价格紧急补购，多买仍按计划量
        全额收费且不予退款。两侧代价不对称，因此需要按照费用结构配置风险余量；
  \item \textbf{跨日状态连续}：问题二没有再要求每天 $0{:}00$ 与 $24{:}00$ 的
        储电量相同，因此电池状态按实际运行结果跨日连续传递，不再每日重置为
        $6000$~kWh，也不再直接采用问题一“全天放电量为充电量的 $0.81$ 倍”这一
        关系（该关系以首尾电量相等为前提）。
\end{enumerate}

相应地，模型由问题一的\textbf{单日确定性 MILP} 扩展为\textbf{三层滚动结构}：
预测层（逐日预测负载与光伏）$\to$ 计划层（在风险修正净负荷下求解日 MILP，
冻结当天 $144$ 段计划购电量）$\to$ 执行层（逐段观测实际值，因果地决定充放电、
紧急购电与弃电，并把实际日末储电量传给次日）。

\subsection{数据准备、时间口径与信息时点}

附件 2 提供 2025 年 $365$ 天、每天 $144$ 个 $10$ 分钟时段的负载功率与光伏
实际功率，经校验无空值、无负值、日期严格递增且恰好覆盖
$2025{:}01{:}01$--$2025{:}12{:}31$。全天合计负载 $40524.1$~MWh、合计光伏
$20251.2$~MWh，功率范围分别为 $1995.72$--$7978.88$~kW 与
$0$--$10216.20$~kW。

时段口径与问题一完全一致：附件 2 的列标签同样采用区间\textbf{结束时刻}，
故第 $j$ 列对应区间 $[(j-1)\Delta t,\ j\Delta t)$。附件 5 中
\texttt{result2.xlsx} 的"计划购电量"表首段标签为 $0{:}10$--$0{:}20$、末段为
$0{:}00$--$0{:}10{+}1$，与问题一模板一样整体错位一格。本文在输出副本中
按正文口径统一改写为 $0{:}00$--$0{:}10$ 至 $23{:}50$--$0{:}00{+}1$，
行序与模板一一对应，原模板文件保持不变。

\textbf{信息时点纪律}：$2025$ 年 $1$ 月被指定为训练与状态预热期，不进入正式
结果；正式输出与评价区间为 $2$ 月 $1$ 日至 $12$ 月 $31$ 日，共 $334$ 天。
$2$ 月 $1$ 日的初始储电量由 $1$ 月逐日实际运行自然递推得到，而非人为设定。
每天的预测、误差分位数与标定参数一律只使用当天之前的已完成数据，计划电量
$g_{n,t}$ 在 $0{:}00$ 一经确定便不再修改。

\subsection{预测模型与数据结构}

本文首先分析附件 2 的 $365$ 天数据，并据此选择预测模型：

\textbf{（1）负载存在极强的星期结构。}把全年按星期分组求日总电量均值，得到
周一至周四及周日约为 $123900$--$124144$~kWh/日，而周五、周六仅约
$78332$--$78407$~kWh/日，两者之比达 $1.58$ 倍。这一结构是\textbf{整体水平}
上的：两族的日内归一化形状高度相似（相关系数 $0.888$，同样呈现凌晨低谷、
上午高峰、午间回落、午后次高、入夜走低的形态），但并不完全一致——以周五、
周六一族为基准，族间逐时段相对差的中位数为 $8.9\%$，在傍晚 $17{:}30$ 前后
最大可达 $38.5\%$（该族在傍晚的相对水平明显更低），而到日末 $23{:}50$ 处
又反向相差 $30.9\%$（周五、周六的相对水平反而更高）。因此若把不同星期的
历史日混在一起做加权平均，既会把两族水平"平均掉"、又无法刻画这一形状差异，
产生系统性偏差。

\textbf{（2）光伏不存在星期结构，而以季节性为主。}按星期分组的光伏日电量均值
极差仅 $1.80\%$，且与星期无明显对应关系，故光伏预测应侧重\textbf{最近的}
历史曲线以跟踪季节变化。

据此采用"近期加权历史值"的预测形式：

\begin{equation}
  \widehat{\ell}_{n,t}=\sum_{i\in\mathcal{H}_n}a_{n,i}\,\ell_{i,t},
  \qquad
  \widehat{v}_{n,t}=\sum_{i\in\mathcal{H}_n}b_{n,i}\,v_{i,t},
  \qquad
  a_{n,i},\,b_{n,i}\ \ge 0,\quad \sum_i a_{n,i}=\sum_i b_{n,i}=1
  \label{eq:p2-forecast}
\end{equation}

其中权重按"周"衰减，$w_{n,i}=d^{\,(n-1-i)/7}$。负载预测取回看窗口
$28$ 天、周衰减因子 $d=0.30$，并只保留与待预测日同一星期的历史日；
光伏预测取回看窗口 $7$ 天、$d=0.30$，使用全部历史日。两组超参数的取值沿用
在 $1$ 月数据上选定，并在正式区间开始前固定，此后
不再调整，从而不引入未来信息。$1$ 月预览也表明按星期分组是必要的：负荷曲线
的星期内规律远强于其逐日平滑性，仅用全部历史日外推会把休息日与工作日混在
一起，净负荷日绝对误差要大出一个量级。

正式区间（$2$ 月 $1$ 日--$12$ 月 $31$ 日）上的预测精度见表~\ref{tab:p2-totals}：
负载平均绝对误差 $1915.8$~kWh/日（相对 $1.73\%$）、光伏 $2114.2$~kWh/日
（$3.70\%$）、净负荷 $3158.8$~kWh/日。

上面三个指标都是\textbf{逐日全天电量}口径的绝对误差，取绝对值后抹去了方向，
而本题的代价恰恰是\textbf{不对称}的——低估触发 $5$ 倍紧急购电，高估只造成
弃电。因此另按\textbf{逐时段}口径统计两个方向，见表~\ref{tab:p2-totals}：
实际净负荷高于点预测的时段占 $48.9\%$、合计 $3158.3$~kWh/日（低估时段平均
低估 $44.8$~kWh/段）；低于点预测的时段占 $51.1\%$、合计 $3167.2$~kWh/日。
两个方向在频次与电量上接近（$48.9\%$ 对 $51.1\%$，$3158.3$ 对
$3167.2$），说明点预测没有明显的系统性偏差。下一节据此利用经验分位数确定
风险余量。

令净负荷预测为 $\widehat N_{n,t}=\widehat\ell_{n,t}-\widehat v_{n,t}$。
负的净负荷表示光伏存在盈余，可用于储能充电，因此建模时保留其原始数值。

\subsection{风险余量与分位数选择}

设某时段随机净负荷为 $N$，计划购电 $g\ge 0$。忽略储能时，期望费用为

\begin{equation}
  \min_{g\ge0}\ pg+5p\,\mathbb{E}\bigl[(N-g)_+\bigr],
  \qquad (x)_+=\max(x,0).
  \label{eq:p2-newsvendor}
\end{equation}

若 $N$ 的分布连续且最优解位于 $g>0$，一阶条件给出

\begin{equation}
  \frac{\partial}{\partial g}=p-5p\,\Pr(N>g)=0
  \quad\Longrightarrow\quad
  F_N(g)=\frac{5-1}{5}=0.8 .
  \label{eq:p2-critical}
\end{equation}

即简化模型中的最优计划量对应 $80\%$ 分位数：多买
$1$~kWh 的确定成本是 $p$，少买 $1$~kWh 的期望成本是 $5p\cdot\Pr(N>g)$，
二者在 $F_N(g)=0.8$ 处平衡。这一结果给出风险参数一个清楚的经济解释，但它
\textbf{只在忽略储能与跨时段耦合时严格成立}，因此本文把它作为参数搜索的
起点而非结论，最终由实际连续运行的总费用校准。

实践中无法直接得到 $N$ 的分布，转而对\textbf{净负荷预测误差}建模。对每个
已经结束的历史日期 $i$，保存其当时利用更早数据作出的预测，计算误差

\begin{equation}
  \varepsilon_{i,t}=(\ell_{i,t}-v_{i,t})-\widehat N_{i,t\mid\text{日期}<i} .
  \label{eq:p2-error}
\end{equation}

这里采用逐日滚动预测产生的样本外误差，以反映实际运行中的预测偏差。取此前
$28$ 天内对应时段误差的经验
$\alpha$ 分位数 $Q_{\alpha,n,t}$，构造风险修正净负荷：

\begin{equation}
  \widetilde N_{n,t}=\widehat N_{n,t}+Q_{\alpha,n,t} .
  \label{eq:p2-risk}
\end{equation}

第 $n$ 天的分位数只取 $\varepsilon_{i,t}$（$i<n$）中已结束日期的样本；
历史样本不足 $10$ 个时改取该时段 $\pm2$ 个相邻时段合并后的分位数，冷启动
阶段仍有可用估计。直接对净负荷误差建模，还自动保留了负载误差与光伏误差
之间的相关性。

\subsection{日前计划模型：风险净负荷下的 MILP}

每天 $0{:}00$ 求解一次。决策变量以\textbf{电量}（kWh）为单位：计划购电量
$g_{n,t}$、参考充电量 $\bar c_{n,t}$、参考放电量 $\bar d_{n,t}$、参考剩余
电量 $\bar w_{n,t}$、参考储电量 $\bar E_{n,t}$，以及模式变量
$z_{n,t}\in\{0,1\}$。带横线的变量表示\textbf{日前参考计划}，不是实际执行结果。

\textbf{目标函数}除购电费外，加入日末储备不足的软惩罚：

\begin{equation}
  \min\ \sum_{t=1}^{144}p_t\,g_{n,t}+\lambda\,\xi_n,
  \qquad
  \xi_n\ \ge\ E^{\mathrm{tar}}-\bar E_{n,144},\quad \xi_n\ \ge\ 0 .
  \label{eq:p2-obj}
\end{equation}

$E^{\mathrm{tar}}=6000$~kWh 是希望为次日保留的参考电量，$\lambda$（元/kWh）
是储备不足的规划代价。该项用于表征日末储电量对后续运行的影响，仅参与计划
优化，不计入实际购电费。
本文并不预设 $\lambda$ 的取值，而是把它与 $\alpha$、$\rho$ 一并交给数据标定
（见 \ref{sec:p2-calib} 节）。

\textbf{约束条件}包括四组：

\begin{equation}
\begin{aligned}
  & g_{n,t}+\bar d_{n,t}=\widetilde N_{n,t}+\bar c_{n,t}+\bar w_{n,t},
  && g_{n,t}\ge0,\ \bar w_{n,t}\ge0 \\
  & \bar E_{n,t}=\bar E_{n,t-1}+\eta_c\,\bar c_{n,t}
    -\frac{\bar d_{n,t}}{\eta_d},
  && \bar E_{n,0}=E_{n,0}^{\mathrm{actual}} \\
  & E_{\min}\le\bar E_{n,t}\le E_{\max},
  && E_{\min}=1200,\ E_{\max}=10800 \\
  & 0\le\bar c_{n,t}\le M z_{n,t},\quad
    0\le\bar d_{n,t}\le M(1-z_{n,t}),
  && z_{n,t}\in\{0,1\}
\end{aligned}
\label{eq:p2-model}
\end{equation}

其中 $M=5000\Delta t=2500/3$~kWh，$\eta_c=\eta_d=0.90$，与问题一保持同一套
母线侧充放电口径。注意平衡式中使用的是\textbf{风险修正后}的净负荷，因此
$\bar w$ 表示规划阶段的剩余量，实际弃电量在执行层根据观测值重新计算。
$\bar c$ 与 $\bar w$ 均不收费；允许 $\bar w$ 包含未使用的计划购电量，以保证
预测偏高时模型仍保持可行。

按变量排列，模型 \eqref{eq:p2-model} 共 $6\times144+1=\mathbf{865}$ 个决策
变量，其中 $144$ 个为二元变量 $z_{n,t}$，其余为连续变量，故是\textbf{混合
整数线性规划}。结构矩阵与问题一一样只依赖时段划分，可\textbf{预先装配一次}，
此后每天只更新等式右端项，单次求解约 $46$~ms。

\subsection{实时执行模型：因果反馈规则}

执行层使用当天 $0{:}00$ 已确定的计划、当前已观测的功率和当前储电量。设使用
储能前的电量盈余为

\begin{equation}
  b_{n,t}=g_{n,t}+v_{n,t}^{\mathrm{actual}}-\ell_{n,t}^{\mathrm{actual}} ,
  \label{eq:p2-surplus}
\end{equation}

$b>0$ 表示计划购电与光伏有剩余，$b<0$ 表示出现缺口。

\textbf{（1）有剩余时充电。}充电量由本段剩余电量、充电功率和储能容量共同确定：

\begin{equation}
  c_{n,t}^{\mathrm{actual}}
  =\min\Bigl\{(b_{n,t})_+,\ M,\
  \frac{E_{\max}-E_{n,t-1}^{\mathrm{actual}}}{\eta_c}\Bigr\} .
  \label{eq:p2-charge}
\end{equation}

\textbf{（2）有缺口时按储备线放电。}在 $0{:}00$ 即可算出当天的储备线

\begin{equation}
  R_{n,t}=E_{\min}+\rho\,\bigl(\bar E_{n,t}-E_{\min}\bigr),\qquad 0\le\rho\le1 ,
  \label{eq:p2-reserve}
\end{equation}

实际放电量为

\begin{equation}
  d_{n,t}^{\mathrm{actual}}
  =\min\Bigl\{(-b_{n,t})_+,\ M,\
  \eta_d\bigl(E_{n,t-1}^{\mathrm{actual}}-R_{n,t}\bigr)_+\Bigr\} .
  \label{eq:p2-discharge}
\end{equation}

$\rho=0$ 表示尽可能用现有储能补足当前缺口；$\rho=1$ 表示将当段参考电量作为
放电下限，以保留更多储能。参数 $\rho$ 由历史运行费用标定。

\textbf{（3）紧急购电、弃电与真实电池状态。}

\begin{equation}
  r_{n,t}=\bigl(-b_{n,t}-d_{n,t}^{\mathrm{actual}}\bigr)_+,
  \qquad
  w_{n,t}^{\mathrm{actual}}=\bigl(b_{n,t}-c_{n,t}^{\mathrm{actual}}\bigr)_+ ,
  \label{eq:p2-residual}
\end{equation}

\begin{equation}
  E_{n,t}^{\mathrm{actual}}
  =E_{n,t-1}^{\mathrm{actual}}
  +\eta_c\,c_{n,t}^{\mathrm{actual}}
  -\frac{d_{n,t}^{\mathrm{actual}}}{\eta_d} .
  \label{eq:p2-state}
\end{equation}

该规则自动避免同时充放电，并保证实际逐段能量守恒：

\begin{equation}
  g_{n,t}+r_{n,t}+v_{n,t}^{\mathrm{actual}}+d_{n,t}^{\mathrm{actual}}
  =\ell_{n,t}^{\mathrm{actual}}+c_{n,t}^{\mathrm{actual}}
  +w_{n,t}^{\mathrm{actual}} .
  \label{eq:p2-actual-balance}
\end{equation}

$w^{\mathrm{actual}}$ 允许来自光伏，也允许来自已经付费的计划购电，因此不设置
"弃电量只能小于光伏电量"的限制。

\textbf{（4）跨日状态传递。}次日初始电量取当天实际执行后的日末
电量：

\begin{equation}
  E_{n+1,0}^{\mathrm{actual}}=E_{n,144}^{\mathrm{actual}} .
  \label{eq:p2-carry}
\end{equation}

由式 \eqref{eq:p2-state} 对全天求和可得状态累计恒等式

\begin{equation}
  E_{n,144}^{\mathrm{actual}}-E_{n,0}^{\mathrm{actual}}
  =\eta_c\sum_{t=1}^{144}c_{n,t}^{\mathrm{actual}}
  -\frac{1}{\eta_d}\sum_{t=1}^{144}d_{n,t}^{\mathrm{actual}} ,
  \label{eq:p2-accum}
\end{equation}

它是本文逐日校验的核心关系之一。只有当某日首尾电量恰好相同时，
$\sum_t d_{n,t}=0.81\sum_t c_{n,t}$ 才成立；问题二中绝大多数日子并不满足，
因此该比例关系不适用于一般的跨日运行情形。

\subsection{参数标定：用过去连续区间的实际总费用选参}
\label{sec:p2-calib}

模型含三个需要选择的参数：风险分位数 $\alpha$、储备线系数 $\rho$ 与日末储备
代价 $\lambda$。标定分为两步。\textbf{第一步}在预热期 $1$ 月
对 $(\alpha,\rho,\lambda)$ 的全部 $180$ 个组合做一次联合标定，用窗口内的实际
总费用选出 $\lambda$，并在正式区间内保持不变。该参数用于刻画日末储电量的
后续经济价值。
\textbf{第二步}从正式区间第一天起每隔 $42$ 天重选一次 $(\alpha,\rho)$——对
每个组合，从\textbf{该日之前}的 $35$ 天窗口起点出发，用窗口起点日 $0{:}00$ 的
实际储电量作初值时序仿真整个窗口，比较窗口内\textbf{包含 $5$ 倍紧急购电费的实际
总费用}，取最小者。首次标定（$2$ 月 $1$ 日）的窗口受数据起点 $1$ 月 $1$ 日
限制，实际只有 $31$ 天；其余 $7$ 次均为完整的 $35$ 天。参数网格为

\begin{equation}
  \begin{aligned}
  \alpha&\in\{0.70,\ 0.75,\ 0.80,\ 0.85,\ 0.90\},\\
  \rho&\in\{0.5,\ 0.6,\ 0.7,\ 0.8,\ 0.9,\ 1.0\},\\
  \lambda&\in\{0,\ 0.1,\ 0.2,\ 0.3,\ 0.5,\ 0.8\},
  \end{aligned}
  \label{eq:p2-grid}
\end{equation}

第一步遍历全部 $180$ 个组合，第二步遍历其中 $5\times6=30$ 个 $(\alpha,\rho)$。
标定所用的历史和时序仿真窗口均截止于标定日前，满足信息时序约束。
标定结果见表~\ref{tab:p2-calib}。

\subsection{结果分析}

\subsubsection{预测误差如何转化为紧急购电成本}

逐时段核对表明，预测偏低会在储能可放电量不足时转化为紧急购电成本。其触发量
由实际净负荷相对风险修正值的超出量与储能剩余可放电量共同决定。$3$ 月 $20$ 日
与 $9$ 月 $23$ 日的储能都在 $20{:}40$ 达到下限
$1200$~kWh，其后分别出现 $1$ 段与 $19$ 段紧急购电；而 $6$ 月 $21$ 日与
$12$ 月 $21$ 日虽分别有 $1$ 段与 $18$ 段超出风险净负荷，储电量最低仍分别停在
$2754$~kWh 与 $1401$~kWh、未触及下限，因而全天未发生紧急购电。这一结果说明
分位数计划需要与储能可用容量结合分析。逐段分解及“$Q_{\alpha}$
有 $8.5\%$ 的时段为负"这一细节，见附录~\ref{app:moved}。

\subsubsection{计划购电与紧急购电的费用贡献}

图~\ref{fig:p2-purchase} 给出四个指定日期的计划购电量、紧急购电量与电价的
对照。计划购电量（蓝色柱）呈现与电价高度相关的形态：在 $0{:}00$--$6{:}00$

出现，说明在风险余量的保护下绝大多数时段的计划量已经足够。

计划购电量并不总是等于实际净负荷：在中午光伏富余的

\subsubsection{标定结果对理论分析的验证}

表~\ref{tab:p2-calib} 给出 $8$ 次滚动标定的选中参数。结果集中：$\alpha$ 在
$8$ 次标定中\textbf{全部落在 $0.70$--$0.90$ 之间}，其中 $0.75$ 出现 $4$ 次、
$0.70$ 出现 $2$ 次、$0.80$ 与 $0.90$ 各 $1$ 次。这一结果与式
\eqref{eq:p2-critical} 的理论预测\textbf{方向一致}：由 $5$ 倍紧急电价导出的
最优分位数在 $0.8$ 附近，而完全基于 $2025$ 年实际数据、按真实总费用选出的
参数也落在 $0.70$--$0.90$ 区间。理论结果与数据标定具有一致性。

$1$ 月联合标定选出的 $\lambda=0.00$ 被冻结整年。这说明在\textbf{$35$ 天窗口
的实际总费用}这一评价口径下，日末储备惩罚并未带来净收益：窗口内的时序仿真已经
包含了储备不足在后续日期引发的紧急购电代价，而电池容量上限（$10800$~kWh）
本身构成了自然的约束；在所用标定窗口内，增加储备惩罚会提高运行费用。变量
$\xi$ 使日末储备的作用能够由数据标定。
$\rho$ 在 $8$ 次标定中取 $0.9$ 五次、$0.5$ 两次、$0.8$ 一次，并未收敛到
某个固定值，同样说明较高的储备线并不必然更省钱。

\subsubsection{弃用电量的成因}

全年弃用电量 $2463544.98$~kWh，占同期光伏发电量 $19068890.0$~kWh 的 $12.9\%$。
题目未对弃电设置惩罚或收益，它不带来额外扣款，但仍是日前计划与实时运行之间
偏差的\textbf{指示器}：其中 $71.8\%$（$1769824$~kWh）是光伏富余超出储能吸纳
能力；另 $28.2\%$（$693721$~kWh）发生在光伏没有富余的时段，来自实际负载低于
预测值时未使用的计划购电量。该部分计划购电成本为 $466267$~元
（占全年计划购电费的 $3.54\%$）。敏感性分析显示，$\alpha$ 由 $0.80$ 降至
$0.50$ 时，弃电由 $2628.6$ 降至 $1493.7$~MWh，紧急购电量由 $177.9$ 增至
$636.1$~MWh，总费用由 $1403.8$ 万元升至 $1508.8$ 万元。完整分解与运营含义见
附录~\ref{app:moved} 与附录~\ref{app:extra}。

\subsubsection{本节小结}

按时间顺序的全年时序仿真表明，风险余量、日前 MILP 与因果执行规则能够协同
利用储能的跨时段调节能力，并将运行费用较无储能基准降低 $24.73\%$。参数均由
决策日前的连续历史窗口标定，完整的基准对照与成因分解见附录~\ref{app:extra}。

\subsection{因果预测模型与净负荷预测误差表}

预测模型只允许访问第 $n$ 天之前的历史日，因此"信息时点"要求由数据结构本身
保证，而不是靠调用约定。净负荷预测误差表 $\varepsilon_{n,t}$ 与
$\alpha,\rho,\lambda$ 无关，故全流程只预计算一次。

\begin{lstlisting}[language=Python]
class ForecastParams:
    """近期加权历史预测的超参数（框架文档 3.2 节）。"""
    window: int = 15            # 回看窗口天数
    decay: float = 0.30         # 每 7 天的权重衰减因子
    weekday_only: bool = False  # 是否只用同一星期的历史
    name: str = "负荷"

# 在正式区间开始前选定并冻结的预测超参数，时序仿真中不再调整。
LOAD_FORECAST = ForecastParams(window=28, decay=0.30, weekday_only=True,  name="负荷")
PV_FORECAST   = ForecastParams(window=7,  decay=0.30, weekday_only=False, name="光伏")

def forecast_weights(n, fp):
    """返回第 n 天预测所用的 (历史日下标, 归一化权重)，只取 i < n。"""
    lo = max(0, n - fp.window)
    idx = np.arange(lo, n)
    if len(idx) == 0:
        return idx, np.zeros(0)
    w = fp.decay ** ((n - 1 - idx) / 7.0)
    if fp.weekday_only:
        same = np.array([weekday_of(i) == weekday_of(n) for i in idx])
        if same.any():
            w = w * same
    s = w.sum()
    if s <= 0:
        return idx, np.full(len(idx), 1.0 / len(idx))
    return idx, w / s

def build_error_table(LOAD, PV, fo):
    """预计算 eps[n, t] = N[n,t] - Nhat[n,t | 日期 < n]。

    这是"逐日向前预测后得到的误差"，不是模型在训练数据上的拟合残差。
    第 0 天无历史，记为 NaN 并永不使用。
    """
    eps = np.full((N_DAY, N), np.nan)
    for n in range(1, N_DAY):
        _, _, nhat = fo.energy(n)
        eps[n, :] = (LOAD[n, :] - PV[n, :]) * TAU - nhat
    return eps

\subsection{风险余量：误差的经验分位数}

\begin{lstlisting}[language=Python]
def risk_margin(eps, n, rp):
    """第 n 天各时段的风险余量 Q_{alpha,n,t}（kWh）。

    只取 n 之前已结束日期的误差；样本不足时合并相邻时段（±2 个 10 分钟），
    仍然只使用历史数据，不引入同日或未来信息。
    """
    if rp.alpha is None or n == 0:
        return np.zeros(N)
    lo = max(0, n - rp.window)
    hist = eps[lo:n, :]
    hist = hist[~np.isnan(hist).all(axis=1)]
    k = hist.shape[0]
    if k >= rp.min_samples:
        return np.quantile(hist, rp.alpha, axis=0)
    if k >= 3:
        pooled = np.empty((k, N))
        for t in range(N):
            a, b = max(0, t - 2), min(N, t + 3)
            pooled[:, t] = hist[:, a:b].mean(axis=1)
        return np.quantile(pooled, rp.alpha, axis=0)
    return np.zeros(N)
\end{lstlisting}

\subsection{日前 MILP 的装配与求解}

决策变量 $x=(g,c,d,w,\bar E,z,\xi)$ 共 $6N+1=865$ 个，其中 $z\in\{0,1\}^{144}$。
系数矩阵与日期无关，故在模块加载时装配一次（\texttt{\_precomp}），逐日只替换

    """装配与日期无关的 MILP 结构，逐日只更换右端项，显著加速。"""
    nvar = 6 * N + 1                       # g | c | d | w | E | z | xi
    iG, iC, iD, iW, iE, iZ, iXi = 0, N, 2*N, 3*N, 4*N, 5*N, 6*N

    # (2) 状态递推：     E_t - E_{t-1} - eta_c c_t + d_t/eta_d = 0   行 N..2N-1
    # (3) 充放电互斥：   c_i - M z_i <= 0,  d_i + M z_i <= M         2N 条

\subsection{实时执行规则}

执行层的核心特征是\textbf{因果性}：第 $t$ 段的动作只依赖本段内已实时测量到的
实际负载与光伏、以及当前储电量，不依赖任何未来时段的信息；购电量 $g_t$ 由
日前冻结、执行层无修改入口。

\begin{lstlisting}[language=Python]
def execute_day(plan_g, Ebar, l_act, v_act, e0, price, rp,
                rule="greedy", allow_storage=True):
    """实时执行：购电计划固定，储能按当前已观测情况因果响应。

    b_t = g_t + v_t - l_t 为使用储能前的电量盈余（kWh）。
    b > 0 用盈余充电（充不进去的弃用）；b < 0 在储备线之上放电，
    剩余缺口按 5 倍电价紧急购电。
    """
    for t in range(N):
        b = plan_g[t] + v_act[t] - l_act[t]
        R = E_MIN + rp.rho * (Ebar[t] - E_MIN)   # 0:00 即可算出的储备线

        if b > 0:
            bpos = min(b, M_ENERGY)
            c[t] = min(bpos, (E_MAX - Ep) / ETA)  # 盈余全部用于充电
            w[t] = b - c[t]                      # 充不进去的弃用（无收益）
        else:
            head = max(0.0, Ep - R)              # 电量不得低于储备线
            d[t] = min(-b, M_ENERGY, ETA * head)
            r[t] = max(0.0, -b - d[t])           # 仍缺的部分紧急购电

        Ep = Ep + ETA * c[t] - d[t] / ETA
        E[t] = Ep

    cost_plan = float(np.sum(price * plan_g))
    cost_emg = float(np.sum(5.0 * price * r))
    return DayExec(g=plan_g.copy(), c=c, d=d, r=r, w=w, E=E, E0=float(e0),
                   cost_plan=cost_plan, cost_emg=cost_emg)
\end{lstlisting}

\subsection{六项一致性检验的独立复核}

结果不依赖求解器自报的可行性，而是用\textbf{未四舍五入}的数据逐日独立复算。

\begin{lstlisting}[language=Python]
def validate_day(rec, tol=1e-6):
    """逐日复核实际运行结果，返回问题清单（空 = 通过）。框架文档 7.2 节。"""
    p = []
    ex, l, v = rec.exec, rec.l_act, rec.v_act

    # 1) 实际逐段供需平衡： g + r + v + d = l + c + w
    resid = ex.g + ex.r + v + ex.d - l - ex.c - ex.w
    scale = max(1.0, float(l.max()))
    if np.abs(resid).max() > tol * scale:
        p.append(f"供需平衡残差 {np.abs(resid).max():.3e} kWh")

    # 2) 物理边界：非负、不超 M、同段不同时充放电
    if ((ex.c > tol) & (ex.d > tol)).any():
        p.append("存在同时充放电的时段")

    # 3) 储电量区间（含日初，共 145 个状态点）
    Eseq = np.concatenate([[ex.E0], ex.E])
    if Eseq.min() < E_MIN - tol or Eseq.max() > E_MAX + tol:
        p.append("储电量越界")

    # 4) 状态累计（问题二不能套用问题一的 sum d = 0.81 sum c）
    lhs = ex.E[-1] - ex.E0
    rhs = ETA * ex.c.sum() - ex.d.sum() / ETA
    if abs(lhs - rhs) > tol * max(1.0, abs(rhs)):
        p.append(f"状态累计不符：dE={lhs:.6f} vs {rhs:.6f}")

    # 5) 费用一致性：弃电不退款，储备罚不混入实际账单
    cp = float(np.sum(_PRICE_REF * ex.g))
    ce = float(np.sum(5.0 * _PRICE_REF * ex.r))
    if abs(cp - ex.cost_plan) > tol * max(1.0, abs(cp)):
        p.append("计划费复算不符")
    if abs(ce - ex.cost_emg) > tol * max(1.0, abs(ce)):
        p.append("紧急费复算不符")

    # 6) 计划购电量在 0:00 后冻结（由架构保证，此处做存在性校验）
    if ex.g.shape != (N,) or ex.g.min() < -tol:
        p.append("计划购电量非法")
    return p
\end{lstlisting}

\subsection{附件 3 的载入与因果分段线性插值}

附件 3 的 $24$ 个值是\textbf{目标整点}的瞬时功率，索引 $j$ 对应发布后 $j$ 小时。
插值的左端节点不能用"预报 $0$ 小时"（附件没有给出），而取发布时刻所在时段的
\textbf{实际}功率，并截断到非负；发布时刻之前的时段返回空值，避免把零填进
分位数样本。

\begin{lstlisting}[language=Python]
def pv_interp_for_issue(anchor_h:int, anchor_v_kw:float, fc24:np.ndarray):
    """返回当天0-24h内144个slot的PV功率预测(kW)，因果插值。超出预报范围的返回nan。"""
    t_nodes=np.arange(anchor_h, anchor_h+25)     # anchor, +1..+24
    v_nodes=np.concatenate([[anchor_v_kw], fc24])
    slot_mid=(np.arange(N)+0.5)/6.0              # 0.083..23.917
    out=np.full(N, np.nan)
    mask=(slot_mid>anchor_h)&(slot_mid<=anchor_h+24)
    out[mask]=np.interp(slot_mid[mask], t_nodes, v_nodes)
    return np.maximum(out,0.0)
\end{lstlisting}

\subsection{负载的因果外推}

负载没有外部预报，只用历史实际值按“同星期优先”外推：先取 $d-7$，
退化时取 $d-1$，再退化时取已有历史均值。任何一支都只用 $d$ 之前的数据。

\begin{lstlisting}[language=Python]
def load_predict(day_idx:int, load_kw:np.ndarray, dates) -> np.ndarray:
    """同星期优先：d-7；无则 d-1；再无则已有均值。因果。返回kW 144."""
    if day_idx-7>=0:
        return load_kw[day_idx-7,:].copy()
    if day_idx-1>=0:
        return load_kw[day_idx-1,:].copy()
    return np.full(N, load_kw[:max(1,day_idx),:].mean() if day_idx>0 else 4000.0)

\subsection{计划 LP：$0{:}00$ 的风险修正日计划}

目标只有购电费与日末储备的引导项，$\xi$ 是日末储电量低于目标值的缺口。模型
不含紧急购电变量，也不含整数变量；购电量只有非负下界，其有效上限由平衡式与
储能容量自然给出。

\begin{lstlisting}[language=Python]
def solve_lp_plan(price, net_risk_kwh, E0, E_tar=6000.0, lam=1.0):
    prob=pulp.LpProblem("plan", pulp.LpMinimize)
    g=[pulp.LpVariable(f"g{i}", lowBound=0) for i in range(N)]
    c=[pulp.LpVariable(f"c{i}", lowBound=0, upBound=M_ENERGY) for i in range(N)]
    d=[pulp.LpVariable(f"d{i}", lowBound=0, upBound=M_ENERGY) for i in range(N)]
    w=[pulp.LpVariable(f"w{i}", lowBound=0) for i in range(N)]
    E=[pulp.LpVariable(f"E{i}", lowBound=E_MIN, upBound=E_MAX) for i in range(N)]
    xi=pulp.LpVariable("xi", lowBound=0)
    prob+=pulp.lpSum([price[i]*g[i] for i in range(N)])+lam*xi
    for i in range(N):
        prob+=g[i]+d[i]==net_risk_kwh[i]+c[i]+w[i]
    for i in range(N):
        prev=E0 if i==0 else E[i-1]
        prob+=E[i]==prev+EC*c[i]-d[i]/ED
    prob+=xi>=E_tar-E[N-1]
    prob.solve(pulp.PULP_CBC_CMD(msg=0))
\end{lstlisting}

\subsection{调整 LP：退款口径的调价项}

问题三主策略采用退款口径，调整项为 $1.5p_tu_t-0.5p_tv_t$；
下调量以初始计划量为上界，保证生效购电量非负。此处两个方向的
调整变量可用线性规划处理：同时抬高 $u_t,v_t$ 会多付
$p_t\delta$，因此最优解中二者不会同时为正。

\begin{lstlisting}[language=Python]
def solve_lp_adjust(price, net_risk_kwh, E0, gP, idx_from, E_tar=6000.0, lam=1.0):
    R=list(range(idx_from,N))
    gA={i:pulp.LpVariable(f"gA{i}", lowBound=0) for i in R}
    up={i:pulp.LpVariable(f"up{i}", lowBound=0) for i in R}
    dn={i:pulp.LpVariable(f"dn{i}", lowBound=0) for i in R}
    ...
    prob+=pulp.lpSum([1.5*price[i]*up[i]-0.5*price[i]*dn[i] for i in R])+lam*xi
    for i in R:
        prob+=gA[i]==gP[i]+up[i]-dn[i]
        prob+=dn[i]<=gP[i]+1e-9
        prob+=gA[i]+d[i]==net_risk_kwh[i]+c[i]+w[i]
    for k,i in enumerate(R):
        prev=E0 if k==0 else E[R[k-1]]
        prob+=E[i]==prev+EC*c[i]-d[i]/ED
    prob+=xi>=E_tar-E[R[-1]]
    prob.solve(pulp.PULP_CBC_CMD(msg=0))
\end{lstlisting}

\subsection{实时执行层：储备线与因果充放电规则}

储备线把参考轨迹 $\bar E_t$ 映射为一个"至少留这么多电"的下限，执行层据此决定
放电深度。规则只用到当段的实际负载与光伏、以及上一段的实际储电量，属于严格的
因果规则。

\begin{lstlisting}[language=Python]
def realtime(gA_kwh, load_kwh_actual, pv_kwh_actual, E0, Ebar_ref, rho=0.5):
    E_prev=E0; c_act=np.zeros(N); d_act=np.zeros(N); r_act=np.zeros(N); w_act=np.zeros(N); E_arr=np.zeros(N)
    for t in range(N):
        b=gA_kwh[t]+pv_kwh_actual[t]-load_kwh_actual[t]
        Rline=E_MIN+rho*(Ebar_ref[t]-E_MIN)
        Rline=min(max(Rline,E_MIN),E_MAX)
        if b>=0:
            c_act[t]=min(b, M_ENERGY, (E_MAX-E_prev)/EC if EC>0 else M_ENERGY)
            c_act[t]=max(c_act[t],0); d_act[t]=0.0
        else:
            need=-b
            maxd=max(0.0, ED*(E_prev-Rline))
            d_act[t]=min(need, M_ENERGY, maxd); c_act[t]=0.0
        r_act[t]=max(0.0, -b-d_act[t])
        w_act[t]=max(0.0, b-c_act[t])
        E_new=E_prev+EC*c_act[t]-d_act[t]/ED
        E_new=min(max(E_new,E_MIN-1e-6),E_MAX+1e-6)
        E_arr[t]=E_new; E_prev=E_new
    return c_act,d_act,r_act,w_act,E_arr
\end{lstlisting}

\subsection{九项一致性检验的独立复核}

校验函数不复用求解时的任何中间量，而是从最终费用记录\textbf{重新按定义计算}，逐日
返回问题清单；只要任一天出现任一条，全年结果即视为不可用。

\begin{lstlisting}[language=Python]
def validate_day(d, price, load_kw, pv_kw, out):
    probs=[]
    # 1 逐段能量平衡：实时层由构造保证 gA + PV + 放电 + 紧急 = 负荷 + 充电 + 弃电
    bal=gA+pv_kw[d,:]*TAU+dd+r-load_kw[d,:]*TAU-c-w
    if np.abs(bal).max()>1e-6: probs.append(f"实际平衡残差{np.abs(bal).max():.2e}")
    # 2 storage bounds
    Eseq=np.concatenate([[E0],E])
    if Eseq.min()<E_MIN-1e-3: probs.append(f"E越下界{Eseq.min():.2f}")
    if Eseq.max()>E_MAX+1e-3: probs.append(f"E越上界{Eseq.max():.2f}")
    # 3 power
    if c.max()>M_ENERGY+1e-6: probs.append("充电越限")
    if dd.max()>M_ENERGY+1e-6: probs.append("放电越限")
    # 4 simultaneous
    if ((c>1e-6)&(dd>1e-6)).any(): probs.append("同时充放电")
    # 5 dynamics
    Erec=[E0]
    for i in range(N): Erec.append(Erec[-1]+EC*c[i]-dd[i]/ED)
    if np.abs(np.array(Erec[1:])-E).max()>1e-4: probs.append("递推不一致")
    # 6 购电量非负
    if (gA<-1e-6).any(): probs.append("gA负")
    # 7 cost recompute
    up=(gA-gP).clip(min=0); down=(gP-gA).clip(min=0)
    c1=float(np.sum(price*gP+1.5*price*up-0.5*price*down))
    if abs(c1-out["cost_plan_adj"])>1e-3: probs.append("计划调整费复算不符")
    c2=float(np.sum(5*price*r))
    if abs(c2-out["cost_emg"])>1e-3: probs.append("紧急费复算不符")
    return probs
\end{lstlisting}

\subsection{价格分解与星期结构}

正文第 \ref{sec:p4-struct} 节的预测式由分解 $P=F+R$ 的四项统计特征确定。
代码计算这些特征并写入结果文件，其中星期结构用于确定同星期加权预测形式。

\begin{lstlisting}[language=Python]
def verify_price_structure(PRICE, FIXED, pp=PRICE_FORECAST):
    R = PRICE - FIXED
    wd = np.array([(datetime.date(2025, 1, 1)
                    + datetime.timedelta(days=n)).weekday()
                   for n in range(N_DAY)])
    means = {int(w): float(R[wd == w].mean()) for w in range(7)}
    eff = np.array([means[int(w)] for w in wd])[:, None]
    return {
        "逐时段均值最大偏差": float(np.abs(PRICE.mean(axis=0)-FIXED).max()),
        "残差与固定曲线相关": float(
            np.corrcoef(R.ravel(), np.tile(FIXED, N_DAY))[0, 1]),
        "残差星期均值": means,
        "星期效应解释比例": float(1-(R-eff).var()/R.var()),
    }
\end{lstlisting}

\subsection{价格预测模型：同星期加权与日内对数修正}

$0{:}00$ 版本是最近三个同星期几价格的加权平均；发布时刻 $\tau>0$ 的版本
再用已完成时段对剩余时段做一次平均对数偏差外推。\textbf{两个版本都只读取
发布时刻之前的数据}，这一约束由切片显式写死，不依赖调用方的自觉。

\begin{lstlisting}[language=Python]
class PriceForecaster:
    def forecast_at(self, n: int, hi: int) -> np.ndarray:
        """第 n 天、第 hi 个发布时刻可用的价格预测 ($\tau$ 之后的时段)。"""
        base = self.forecast0(n)                    # 同星期加权，只用 < n 的天
        b = self.pp.beta_at(hi)                     # β 逐发布时刻取值
        if hi == 0 or b == 0.0:
            return base
        t0 = 36 * hi                                # 发布时刻对应的时段索引
        obs, pred = self.PRICE[n, :t0], base[:t0]
        m = (obs > 0) & (pred > 0)
        if m.sum() < 6:                             # 已完成样本过少则不修正
            return base
        # 只用已经实现的 [0, t0) 段估计平均对数偏差，外推到 [t0, 144)
        bias = float(np.mean(np.log(obs[m] / pred[m])))
        out = base.copy()
        out[t0:] = base[t0:] * np.exp(b * bias)
        return np.maximum(out, 1e-6)
\end{lstlisting}

\subsection{联合风险：以实际电价为权的经验分位数}

正文第 \ref{sec:p4-risk} 节把风险余量从等权分位数换成价格加权分位数。
实现上是一段带权分位数函数：权重为\textbf{同一目标时段}的历史实际电价，
权重和为零时退回普通分位数，避免样本缺失导致静默出错。

\begin{lstlisting}[language=Python]
def _weighted_quantile(x: np.ndarray, q: float, w: np.ndarray) -> np.ndarray:
    # x、w 均为 (历史日期, 目标时段) 矩阵，按列取经验分位数
    o = np.argsort(x, axis=0)
    xs = np.take_along_axis(x, o, axis=0)
    ws = np.take_along_axis(w, o, axis=0)
    cw = np.cumsum(ws, axis=0)
    tot = cw[-1]
    plain = np.quantile(x, q, axis=0)
    ok = np.isfinite(tot) & (tot > 0)
    tgt = np.where(ok, q * tot, np.inf)[None, :]
    reached = cw >= tgt
    hit = reached.any(axis=0)
    idx = reached.argmax(axis=0)
    out = xs[idx, np.arange(x.shape[1])]
    return np.where(hit, out, plain)
\end{lstlisting}
