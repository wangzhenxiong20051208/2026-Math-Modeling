# C 题提交材料

本目录汇总 C 题“微网与外部电网电力调控策略”的交付件与复现材料。论文采用
`05_论文/final_new/main.pdf` 的编译结果；问题一至问题三使用当前定稿数据与代码，
问题四采用退款计费主口径。

| 目录 | 内容 |
| --- | --- |
| `论文/` | 最终论文 PDF |
| `结果文件/` | 题目要求提交的五个 Excel 结果文件 |
| `源代码/` | 生成结果、表格与插图所需的 21 个 Python 脚本 |
| `支撑数据/` | 运行明细、标定记录、预测误差与汇总结果 |
| `题目与附件/` | 原题及附件 1--4，作为代码输入数据 |
| `环境/` | Python 运行依赖 |
| `说明/` | 交付清单与文件校验和 |

## 题目要求的结果文件

| 文件 | 对应任务 |
| --- | --- |
| `result1.xlsx` | 问题一：确定性单日计划 |
| `result2.xlsx` | 问题二：日前计划与紧急购电 |
| `result3.xlsx` | 问题三：多版本预报下的滚动调整 |
| `result4-2.xlsx` | 问题四：波动电价下的问题二结果 |
| `result4-3.xlsx` | 问题四：波动电价下的问题三结果 |

## 复现说明

安装 `环境/requirements-cumcm.txt` 中列出的依赖后，可从原仓库根目录运行源代码。
源脚本保留了原仓库的输入输出相对路径；若单独复现本提交包，需将 `题目与附件/` 和
`支撑数据/` 映射回脚本所需的 `01_题目/C题/` 与 `06_支撑材料/` 目录。问题四生成论文
主口径结果时使用：

```bash
python3 源代码/p4_microgrid.py --refund-main
```

`结果文件/` 中的 Excel 文件是当前定稿对应的交付结果；`说明/SHA256SUMS.txt`
提供论文和五个交付表格的 SHA-256 校验值。
