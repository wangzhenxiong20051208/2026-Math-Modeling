# 2026-Math-Modeling

2026 全国大学生数学建模竞赛三人仓库。

## 本地路径

请把 GitHub Desktop / OpenCode 都打开这个文件夹：

`D:\GitHub\2026-Math-Modeling`

不要再往 `C:\Users\...\Documents\GitHub` 里克隆。

## 怎么同步（改完就推）

1. 在这个文件夹里改代码、数据、论文
2. 打开 **GitHub Desktop**
3. 左边能看到改动 → 写一句说明 → **Commit to main** → **Push origin**
4. 另外两个人在 GitHub Desktop 点 **Fetch origin**，有更新再 **Pull**

云端地址：https://github.com/wangzhenxiong20051208/2026-Math-Modeling
