## 2. 地基问题：调减到底怎么计价（三问共用）

> **本节已重写两次，最终结论：退款口径为主、主口径为已披露的保守臂。**
> 初稿说"退款口径是唯一字面读法、我方错了"；第一轮复核**推翻**它、改判主口径；
> 本轮独立裁决（5 视角钢人 + 3 名盲评裁判，见 §2.6）**又回到退款口径**，
> 但**换了判据**、且**不再声称对方错**。三轮反复的痕迹保留在下面，因为
> "为什么两种读法都能自圆其说、以及最终靠什么分出高下"本身就是结论的一部分。

### 2.1 题面原文

`01_题目/C题/out.txt` 第 60–63 行：

> 计划购电量高于调整购电量的部分，**违约电价是交易时刻电价的 50%**。调整购电量高于
> 计划购电量的部分，超出部分的电价是交易时刻电价的 1.5 倍。总的购电费用包括计划购电
> 费用、紧急购电费用和调整购电量的相关费用。

### 2.2 两种读法

| 读法 | 费用式（下调一侧） | 谁在用 |
|---|---|---|
| **主口径 C**（不退款，另计违约费） | $p g^0+0.5p(g^0-x)_+$ | 我方现行主模型（框架 §3.2 的显式选择） |
| **退款口径 D**（退回原价，净收 50%） | $p g^0-0.5p(g^0-x)_+ = p x+0.5p(g^0-x)_+$ | **王、贾**（均未在论文中声明）；**本文建议改此为主口径** |

两式在 $x\ge g^0$（上调一侧）**逐字相同**；**分歧只在被取消的那一项 $(g^0-x)_+$ 的符号**：
C 取 $+0.5p$，D 取 $-0.5p$。等效说法是"被取消那部分电量（不含沉没计划价）的净单价"：
C 下 $1.5p$、D 下 $0.5p$。注意**不要**把它表述成"基数决定加项还是减项"——
两读法的**基数都是 $g^0$**，差的是符号。

### 2.3 最终判据：为什么文本略偏向退款口径 D

**先说被否掉的三条论证**——它们听起来有力，但都站不住：

1. **"两向都等于 1.5 倍收款，所以没必要写两句"（我方最初的反驳）——基准点混淆，不成立。**
   读法 C 下以"恰好按计划执行"为基准的**边际**代价是：下调 $+0.5p$、上调 $+1.5p$，**并不相同**。
   "都等于 $1.5p$"是把"被取消那度电的**沉没总代价**（已付 $p$ 加罚 $0.5p$）"与"多买那度电的
   **边际价** $1.5p$"并置得来的，两个 $1.5p$ 不同源。而且读法 D 同样要写两个数（$0.5$ 与 $1.5$），
   "写了两句"对 C、D 完全对称——**这条若成立会同时否掉 D**。它最多说明 C 的账看起来怪，
   不构成文本证据。
2. **"问题二写了按计划量计费，是主口径的直证"——上一轮我加的，是过度声称，撤回。**
   `out.txt:40`「除紧急购电费用外，其他时间段的购电费用均按计划购电量计算」只锁定
   **"计划购电费用"这一科目的计提基数为 $g^0$**。C 记成 $\sum p g^0$，D 也记成 $\sum p g^0$
   （退款记在"调整购电量的相关费用"这一科目内）——**两读法在该句下完全相容**
   （框架 §3.3 的公式构造本身就证明了这一点）。它排除的只是"只按实际用量 $p x$ 计费"这**第三**种读法。
   把"计提基数条款"读成"退款禁止条款"，是把一条对 C/D 中性的条文误当直证。
   （另注：问题二里 $A\equiv P$，两读法都退化成同一个式子，**它连区分 C/D 的能力都没有**。）
3. **"5 倍紧急电价也能不触发，所以'0.5 是死参数'不成立"——类比不成立。**
   $5p$ 是**该度电的真总价**，其威慑力正来自"不买就付 $5p$"——它进一阶条件、在均衡外改变收益。
   C 下的 $0.5p$ 既不是被取消电量的总价，也不进一阶条件、不进任何一天的账单——
   **连均衡外都不起作用**。两者性质不同，不能互证。

**真正的两条判据（都指向 D）：**

**判据一：题面自己的模板。** 同一份题面里，"电价是交易时刻电价的 $N$ 倍"出现三次：

| 位置 | 原句 | 三方的读法 |
|---|---|---|
| `out.txt:39` | 紧急购电"其电价是交易时刻电价的 5 倍" | 一致：该电量**总价** $5p$ |
| `out.txt:61` | "超出部分的电价是交易时刻电价的 1.5 倍" | **一致：该电量总价 $1.5p$**（框架 §3.2 自己写明"不是先付原价再加 1.5 倍成 2.5 倍"） |
| `out.txt:60` | "违约电价是交易时刻电价的 50%" | 争议点 |

前两处无争议地是"该部分电量的**总价**"。60 行与 61 行是**紧邻、同构**的两句
（`[某个"部分"的电量]，[其]电价是交易时刻电价的 N`），按"同段同句式同解释"，
60 行只能是"被取消那部分电量按 $0.5p$ **结算**"。读法 C 会让 60 行成为三处同模板里
**唯一一处"倍数是附加率"的例外**——而命题人手上明明有"违约金/罚金/加收/另收"这些词
（grep 全篇：`退/返还/冲抵/抵扣/违约金/罚金/加收/另收/多退少补` **零命中**），
偏偏在这里用了"**电价**"这个单价词。

**判据二："0.5"在 C 下是死参数。** 框架 §3.2 自己写下这条推论："允许无偿弃用剩余电量时，
向下调整没有费用优势"，故主模型直接把 $x_t\ge g_t^0$ 当约束；`p3_microgrid.py:481-491` 的
`convention=="main" → ub=0` 就是它的实现。后果不只是"该分支不触发"，而是**系数 $0.5$ 本身
在模型里无作用**（给任何正数都得同一个最优解）。命题人把整问建立在"**调整**"之上，
却给出一个数学上不存在的费率——这比"写一条完备但不激活的分支"可疑得多。
而 D 下 $0.5$ 与 $1.5$ 关于基准价 $1.0$ 恰好对称（$1\mp 0.5$，即电力市场标准的"偏差考核 ±50% 价带"），
两个系数都真实出场。

**判据一的唯一裂缝（诚实记下）：** 紧急 $5p$ 与超出 $1.5p$ 修饰的是"**未付过款的新购电量**"，
而被取消那部分是"**已在计划费里计过 $p$ 的电量**"。对前者，"总价 $=$ 单价 $\times$ 数量"与
"唯一收费"自动重合；对后者两者会分离。所以严格讲，同模板只推出"$0.5p$ 是被取消那部分电量的
**单位费率**"（这点 C 也承认），**并不直接推出**"它就是该部分电量的**全部**收费"。
补上这一刀的是判据二（机制层），不是模板本身。因此这是**倾向**而非定论，置信度 $0.6$ 量级。

**王那段"证伪"（`q3-wang/03_代码/p3_microgrid.py` 模块 docstring）方向对但不是证明**：
它说"下调反而多付费，与题设'可调整'矛盾"——这**默认了**"可调整"必须**能省钱**。
但在 C 下，"可调但下调不划算"是可以自洽的（就是判据二说的那种设计）；所以该论证
本身不成立，**不过它指的方向由判据二重新给出**。

### 3.6 一个附带发现：标定结果对网格**非单调**

这条是移植过程中的副产物，**结论至今成立，也是"不能只换网格就宣称更优"的依据**。

做过一版中间方案：**只把贾的 $\rho$ 细网格装进我方引擎、其余不动**（即 §3.5 那张表
的前两行），得 13 958 010.35 元。而这在数学上不该发生：

- 我方旧的 $\rho\in\{0,1\}$ 是我方新网格 $\rho\in\{0,\dots,1.0\}$ 的**严格子集**
  （$\alpha$ 网格也同步扩了内点，同为严格扩张）；
- 子集上的"最优解"却**比超集上的还贵 63 554.77 元**（14 021 565.12 → 13 958 010.35）。

**超集的最优必然不劣于子集的最优。** 唯一解释是：**滚动标定是一个非单调的过程**
——每 42 天在 35 天回放窗上选参，扩大候选集会让某几轮选中不同的参数，改变此后的
状态轨迹，从而在长期上未必更优；它优化的是**回放窗内的历史费用**，不是全期费用。
（§3.5.1 的逐日表就是这个机制的微观证据：$\lambda=0$ 的日子，目标值相同而取到的
极点不同，几个 kWh 的放电差就顺着跨日状态传到期末。）

所以：

- 这一条**不是"我们算错了"**，而是"滚动标定的近视性"这一固有性质；
- 它意味着**移植之后必须重跑全部结果**，不能只替换网格就宣称更优——所以本轮不是
  在旧结果上打补丁，而是把 4-2 / 4-3 一并重算；
- 也意味着**"谁的网格更大谁更省"不成立**。§3.5 之所以最终选择整份内核算法的统一
  移植（而不是继续做参数级的混合），就是为了让"选中了什么"这件事**两边完全一致**，
  避免把路径依赖的噪声当成方法优劣——逐项验证的结果（§3.5.1）证实了这一选择是对的。

### 4.5 选型结论

**以我方引擎为主体，计费口径改以"退款口径"为主，旧主口径降为已披露的保守臂。** 理由：

1. 我方引擎在可复现性、校验完备度（334 天逐日校验）、消融覆盖度上全面领先；
2. 计费口径经 5 视角钢人 + 3 名盲评裁判独立裁决，**三名裁判一致倾向退款口径**
   （0.56/0.60/0.63，见 §2.6）——判据是题面三处"电价是交易时刻电价的 N 倍"同模板
   与"0.5 在主口径下是死参数"，**不是**"两向都等于 1.5 倍"（该论证已否，见 §2.3）；
   **但这是倾向不是定论**：主口径有"问题二基数条款 + 全题无'退'字"这条真实依托，
   故旧主口径必须作为已披露的臂并列，不能删；
3. **改口径不需要重算**：两臂的优化都已跑完（13 396 937.79 与 13 457 697.61），
   只是叙述层的主从互换（§2.5 成本提示）；按 §2.5 第 2 条把"两臂各自独立标定"写清楚；
4. **必须在论文里点名的**是跨队不可比：王的 13 384 828.87 与贾的 13 286 130.98 属退款口径，
   与我方**旧主口径** 13 457 697.61 不能直接排名——改 D 为主口径后，
   我方 13 396 937.79 反而与王/贾同口径可比（与王差 0.09%）。

**不选贾**：没有 `result3.xlsx`、不可复现、光伏对齐口径偏低约 40%、还多加了 `up_limit` 约束。
**吸收贾的一条**：把标定纪律（1 月选型 → 冻结 → 全程固定）在论文里写成显式声明。
**吸收王的一条**：分时段 $Q_t$ 的**同条件对照纪律**（我方已是逐段分位，只需按这个格式
补一张"标量 Q vs 逐段 $Q_t$"的消融行）。
